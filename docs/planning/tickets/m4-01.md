# 提前查明社交数据与支付路径的可行性缺口 (M4-01)

## Parent

[只开放有真实数据和收付款证据的平台能力](../specs/m4-spec.md) · M4-SPEC · M4。版本控制中的范围与验收记录；执行状态以关联 GitHub issue 为准。

## What to build

无需等待M2/M3，整理可复核的官方资料和验证脚本计划，尽早发现无法计量或无法付款的路径。

## Inputs and boundaries

已批准范围、canonical规则与内部接口契约；不依赖任何阶段实现。

交付一个可演示/可验证的窄闭环，包含本路径所需存储约束、服务器授权、页面状态、事件通知、运营恢复和测试；不拆成“只建表/只做页面”。证据/批准票交付可执行结论和验证记录，不伪造代码交付。按本票边界实现；没有相应改动则不硬建新层。

业务默认数值、时长、费率、门槛和取整规则只引用[canonical默认源](../../../phase-0/foundation/campaign-defaults-v1.md)，不能从本文另抄常量。平台/财务未知按父规格门槛处理。

## Acceptance criteria

- [ ] [M4-AC01](../specs/m4-spec.md#m4-ac01) / 1 — 为TikTok、Instagram/Meta、YouTube逐项建立权限/账号类型/用途许可/稳定ID/基线/截止覆盖/地区/配额/撤权矩阵，注明官方URL、查阅日期和未知字段。
- [ ] [M4-AC01](../specs/m4-spec.md#m4-ac01) / 2 — 为候选付款路径列马来西亚独立主体、国家/币种组合、资金持有人、账户可用证据、幂等/查询/退款及费用问题；Stripe仅候选。
- [ ] [M4-AC01](../specs/m4-spec.md#m4-ac01) / 3 — 形成正向/缺失/拒绝样本和可执行沙盒验证步骤、责任角色及失败退出条件；文档未确认项标未知，不调用未授权账户。

## Blocked by

None (can start immediately).

只在上述前置的实际输出可用时执行；依赖完成不自动证明本票通过。能力调查的否定结论只允许后续禁用实现，绝不授权live开放。

## Verification and recovery

另一实施者可按矩阵复核来源和运行计划；资料调查不能标能力已通过。

本路径测试命名含 `M4-AC01`，证据写明代码/配置版本、环境、动作、期望、实得和未通过项。涉及资金、组织或任务状态用真实PostgreSQL集成测试；涉及用户操作给端到端证据，包含至少一个实质失败/越权场景。门槛票以原始证据和实际签核验收，不以测试替代许可。UI沿用设计系统、三语与手机约束；通知不得漏给正确接收方或误发他人。
