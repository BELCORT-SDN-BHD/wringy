## Acceptance criteria

- [ ] [M3-AC08](../specs/m3-spec.md#m3-ac08) / 1 — 正常截止、恰到截止与超出截止测试明确：计量覆盖截至终点且不含终点之后观看；申请在服务端验证时间不晚于deadline才接受，不依据设备时间。
- [ ] [M3-AC08](../specs/m3-spec.md#m3-ac08) / 2 — 受阻者从最终窗口数据可用和阻挡解除两者较晚时间取得完整公布宽限；原因、时间与新deadline持久化并通知，仅影响相关投稿。
- [ ] [M3-AC08](../specs/m3-spec.md#m3-ac08) / 3 — 延期不增加观看、不补历史优先级、不保证预算；重复调度不无限延长；及时提交及已确认款在截止后仍保留。
