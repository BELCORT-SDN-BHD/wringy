## Acceptance criteria

- [ ] [M2-AC03](../specs/m2-spec.md#m2-ac03) / 1 — 创建者在新组织获得商家管理权限；加入已有组织必须有授权授予记录，无自助运营/财务提权入口。
- [ ] [M2-AC03](../specs/m2-spec.md#m2-ac03) / 2 — 每次读写重核实际成员、组织和能力；API及复合关系约束拒绝跨组织对象组合，切换前的缓存或请求不能写入另一组织。
- [ ] [M2-AC03](../specs/m2-spec.md#m2-ac03) / 3 — 创作者账号资料只对本人开放；内容审核和财务能力独立；越权读取、修改和授予权限均拒绝并留下不泄露秘密的审计。

## Verification and recovery

一个双角色账号与两个组织完成切换/越权用例；回退撤销新增授权而保留业务记录。

本路径测试命名含 `M2-AC03`，证据写明代码/配置版本、环境、动作、期望、实得和未通过项。涉及资金、组织或任务状态用真实PostgreSQL集成测试；涉及用户操作给端到端证据，包含至少一个实质失败/越权场景。门槛票以原始证据和实际签核验收，不以测试替代许可。UI沿用设计系统、三语与手机约束；通知不得漏给正确接收方或误发他人。
