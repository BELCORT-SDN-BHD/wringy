# 用真实试运营结果决定继续修复或扩大开放 (M5-09)

## Parent

[获邀用户能在可恢复且有人负责的环境试运营](../specs/m5-spec.md) · M5-SPEC · M5。版本控制中的范围与验收记录；执行状态以关联 GitHub issue 为准。

## What to build

汇总真实使用、拒绝申诉、资金和恢复结果，创办人决定继续当前范围、修复、暂停或扩大。

## Inputs and boundaries

M5-08 按批准范围发布并完成首批邀请旅程

交付一个可演示/可验证的窄闭环，包含本路径所需存储约束、服务器授权、页面状态、事件通知、运营恢复和测试；不拆成“只建表/只做页面”。证据/批准票交付可执行结论和验证记录，不伪造代码交付。按本票边界实现；没有相应改动则不硬建新层。

业务默认数值、时长、费率、门槛和取整规则只引用[canonical默认源](../../../phase-0/foundation/campaign-defaults-v1.md)，不能从本文另抄常量。平台/财务未知按父规格门槛处理。

- [ ] [M5-AC09](../specs/m5-spec.md#m5-ac09) / 1 — 按spec指标定义给出分子/分母、时间范围、来源和样本不足，不把邀请/浏览/模拟支付当付费或复购。
- [ ] [M5-AC09](../specs/m5-spec.md#m5-ac09) / 2 — 每笔未清款和案件有负责人及下一动作；整理用户卡点、支持成本和缺陷，验收外反馈明确进入变更记录等待fix-now/queued决定。
- [ ] [M5-AC09](../specs/m5-spec.md#m5-ac09) / 3 — 记录复盘“什么出乎意料、哪一条规则应改变”，规则变更经PR；扩大开放必须另有明确决定，不因达到人数或本票关闭自动放量。

## Verification and recovery

报告可追溯、创办人决定及实际日期；无充分样本可决定延长观察，不虚构成功。

本路径测试命名含 `M5-AC09`，证据写明代码/配置版本、环境、动作、期望、实得和未通过项。涉及资金、组织或任务状态用真实PostgreSQL集成测试；涉及用户操作给端到端证据，包含至少一个实质失败/越权场景。门槛票以原始证据和实际签核验收，不以测试替代许可。UI沿用设计系统、三语与手机约束；通知不得漏给正确接收方或误发他人。
