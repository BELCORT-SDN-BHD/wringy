## Acceptance criteria

- [ ] [M2-AC04](../specs/m2-spec.md#m2-ac04) / 1 — 严格沿用语言规范解析顺序及locale，访客跳过不记明确偏好，共享设备访客偏好不覆盖另一账号。
- [ ] [M2-AC04](../specs/m2-spec.md#m2-ac04) / 2 — 保存后新浏览器登录恢复偏好；保存失败只提示未保存，允许重试；当前会话明确选择不被旧账号值覆盖。
- [ ] [M2-AC04](../specs/m2-spec.md#m2-ac04) / 3 — 三语关键状态和无障碍名齐全；切换保留输入和请求键、不重复提交；金额/时区/规则版本/用户原文不变，关键确认缺译时禁止确认。

## Verification and recovery

三語桌面/手机完成选择→保存→换设备→失败重试；回退保持已有偏好数据可读。

本路径测试命名含 `M2-AC04`，证据写明代码/配置版本、环境、动作、期望、实得和未通过项。涉及资金、组织或任务状态用真实PostgreSQL集成测试；涉及用户操作给端到端证据，包含至少一个实质失败/越权场景。门槛票以原始证据和实际签核验收，不以测试替代许可。UI沿用设计系统、三语与手机约束；通知不得漏给正确接收方或误发他人。
