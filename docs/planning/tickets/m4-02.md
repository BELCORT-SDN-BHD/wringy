# 取得实际主体及授权测试账号的使用证据 (M4-02)

## Parent

[只开放有真实数据和收付款证据的平台能力](../specs/m4-spec.md) · M4-SPEC · M4。版本控制中的范围与验收记录；执行状态以关联 GitHub issue 为准。

## What to build

落实马来西亚独立公司的准确身份、合法授权测试账号及允许验证范围，给后续真实验证明确边界。

## Inputs and boundaries

M4-01 提前查明社交数据与支付路径的可行性缺口

交付一个可演示/可验证的窄闭环，包含本路径所需存储约束、服务器授权、页面状态、事件通知、运营恢复和测试；不拆成“只建表/只做页面”。证据/批准票交付可执行结论和验证记录，不伪造代码交付。按本票边界实现；没有相应改动则不硬建新层。

业务默认数值、时长、费率、门槛和取整规则只引用[canonical默认源](../../../phase-0/foundation/campaign-defaults-v1.md)，不能从本文另抄常量。平台/财务未知按父规格门槛处理。

## Acceptance criteria

- [ ] [M4-AC02](../specs/m4-spec.md#m4-ac02) / 1 — 创办人提供/确认主体与拟开放国家、首版币种假设；记录具体负责人，未提供不以Belcort或任意公司替代。
- [ ] [M4-AC02](../specs/m4-spec.md#m4-ac02) / 2 — 按平台记录应用、账户所有者、测试账号、已获scope、用途许可和允许测试的环境；缺授权保持阻塞，不把Google登录当社交授权。
- [ ] [M4-AC02](../specs/m4-spec.md#m4-ac02) / 3 — 对实测资金另列允许主体、收付款方、金额上限及环境的具体授权；无资金授权只做非资金/沙盒测试，不记录虚构批准日期。

## Blocked by

只在上述前置的实际输出可用时执行；依赖完成不自动证明本票通过。能力调查的否定结论只允许后续禁用实现，绝不授权live开放。

## Verification and recovery

交付来源可查的授权范围；敏感凭据使用安全引用，授权被撤回则停相应测试。

本路径测试命名含 `M4-AC02`，证据写明代码/配置版本、环境、动作、期望、实得和未通过项。涉及资金、组织或任务状态用真实PostgreSQL集成测试；涉及用户操作给端到端证据，包含至少一个实质失败/越权场景。门槛票以原始证据和实际签核验收，不以测试替代许可。UI沿用设计系统、三语与手机约束；通知不得漏给正确接收方或误发他人。
