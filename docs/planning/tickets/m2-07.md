# 创作者提交外部链接后能查回自己的投稿 (M2-07)

## Parent

[用户登录后能跨浏览器保存活动与投稿](../specs/m2-spec.md) · M2-SPEC · M2。版本控制中的范围与验收记录；执行状态以关联 GitHub issue 为准。

## What to build

创作者查看明确模拟的账号资格并保存外部链接，之后可从另一浏览器查到同一投稿和待基线状态。

## Inputs and boundaries

M2-06 访客能分享公开活动并登录继续参与；M2-03 同一用户能在本人和获授权商家组织间切换

交付一个可演示/可验证的窄闭环，包含本路径所需存储约束、服务器授权、页面状态、事件通知、运营恢复和测试；不拆成“只建表/只做页面”。证据/批准票交付可执行结论和验证记录，不伪造代码交付。按本票边界实现；没有相应改动则不硬建新层。

业务默认数值、时长、费率、门槛和取整规则只引用[canonical默认源](../../../phase-0/foundation/campaign-defaults-v1.md)，不能从本文另抄常量。平台/财务未知按父规格门槛处理。

## Acceptance criteria

- [ ] [M2-AC07](../specs/m2-spec.md#m2-ac07) / 1 — 只接收允许平台URL并规范化稳定发布ID；无视频上传或处理入口；短链解析受允许域及重定向约束，不提供任意地址下载代理。
- [ ] [M2-AC07](../specs/m2-spec.md#m2-ac07) / 2 — fixture归属验证拒绝他人账号；同活动重复URL返回同投稿；账户冲突进入复核，不能自动转给另一人。
- [ ] [M2-AC07](../specs/m2-spec.md#m2-ac07) / 3 — 缺基线保持待接受；所有模拟账号和来源明确标示；投稿绑定本人、组织及规则版本，跨组织关系和私密查询被拒绝。

## Verification and recovery

保存、重复短链、错误归属、无基线、换设备回读；停新投稿保留原记录。

本路径测试命名含 `M2-AC07`，证据写明代码/配置版本、环境、动作、期望、实得和未通过项。涉及资金、组织或任务状态用真实PostgreSQL集成测试；涉及用户操作给端到端证据，包含至少一个实质失败/越权场景。门槛票以原始证据和实际签核验收，不以测试替代许可。UI沿用设计系统、三语与手机约束；通知不得漏给正确接收方或误发他人。
