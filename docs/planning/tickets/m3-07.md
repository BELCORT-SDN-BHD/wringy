## Acceptance criteria

- [ ] [M3-AC07](../specs/m3-spec.md#m3-ac07) / 1 — 申诉仅本人且在适用期限内受理；截止边界采用服务端时钟；已受理案件无虚构自动过期释放。
- [ ] [M3-AC07](../specs/m3-spec.md#m3-ac07) / 2 — 成立保留原序列/预留并恢复对应审核；驳回或期限结束无申诉经再次核查才最终释放，一次释放一笔分录。
- [ ] [M3-AC07](../specs/m3-spec.md#m3-ac07) / 3 — 申诉提交与释放定时任务竞争测试不误释放；结论、释放及通知同事务/outbox；已确认/已付争议不能走普通释放。

## Verification and recovery

时间边界、重复结论、并发申诉与释放；回退暂停释放并交接未决案件。

本路径测试命名含 `M3-AC07`，证据写明代码/配置版本、环境、动作、期望、实得和未通过项。涉及资金、组织或任务状态用真实PostgreSQL集成测试；涉及用户操作给端到端证据，包含至少一个实质失败/越权场景。门槛票以原始证据和实际签核验收，不以测试替代许可。UI沿用设计系统、三语与手机约束；通知不得漏给正确接收方或误发他人。
