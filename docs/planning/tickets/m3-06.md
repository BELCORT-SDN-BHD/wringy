## Acceptance criteria

- [ ] [M3-AC06](../specs/m3-spec.md#m3-ac06) / 1 — 审核按范围分权，内容通过不等于计量通过；暂缓数据不被当作拒绝作弊；所有决定有版本、证据、操作者及原因。
- [ ] [M3-AC06](../specs/m3-spec.md#m3-ac06) / 2 — 拒绝展示受影响金额、申诉期限和入口；拒绝后预留不释放，过审核目标只升级通知不自动通过。
- [ ] [M3-AC06](../specs/m3-spec.md#m3-ac06) / 3 — 同一决定重试及相互冲突审核使用版本/请求去重；只有全部必要审核通过才可进入确认，利益冲突转交另一个获授权审核者。

## Verification and recovery

分角色审核、越权及超时任务重放；停决定入口保留现状和争议资金。

本路径测试命名含 `M3-AC06`，证据写明代码/配置版本、环境、动作、期望、实得和未通过项。涉及资金、组织或任务状态用真实PostgreSQL集成测试；涉及用户操作给端到端证据，包含至少一个实质失败/越权场景。门槛票以原始证据和实际签核验收，不以测试替代许可。UI沿用设计系统、三语与手机约束；通知不得漏给正确接收方或误发他人。
