规格文件维护范围、规则和验收；对应父 issue 管理子任务与执行。任务文件是创建来源，实时状态、负责人及前置依赖以 GitHub 为准。catalog.json 提供机器可检查的规格/票据关系。

外部可行性调查可立即并行。后续实施等待前置交付；重型实施规格批准遵守创办人项目治理规则，可以在一次完整审阅中覆盖多阶段，无需重新开 Wayfinder。提供方准入、具体财务政策和生产发布仍需真实证据或明确决定。任务数量不代表所有能力已验证，也不构成固定总工期承诺。
