## 3. Request flow (as built)

1. `GET /internal` (no cookie, internal mode) → `proxy.ts` → 307 `/internal/sign-in?next=/internal`.
2. The sign-in page posts `next` to `POST /auth/sign-in` → mode guard → Origin rule → writes `wringy-auth-next` → `signInWithOAuth({ provider: 'google', options: { redirectTo: APP_ORIGIN + '/auth/callback', skipBrowserRedirect: true } })` (the PKCE verifier lands in an `httpOnly` cookie through `setAll`) → `noStore()` → 303 to Supabase → Google consent (`scope=email profile`).
