# Wringy 视觉与组件规范 v3 · 独立草案

2026-09-10。状态：已获授权制作新视觉指南草案；尚非获批的生产设计系统，也不构成商业模型审批。面向品牌审核人员、创作者，以及投资者材料制作人员。成功标准：看清当前对象、识别下一步、不会把审核或资格误读成已付款。

## 1. 来源与边界

本规范处于「品牌方向 → 设计系统 → 组件 → 原型」链条；本次明确方向是白色工作面、酸柠黄、深森林色章节、真实感摄影，应用结构参考 Linear，品牌叙事参考 Ramp。所有颜色、尺寸、响应断点、文案、交互及业务状态映射均为 **Wringy 独立提案**。不能称为“完整提取 Ramp 官方规范”。

研究基线：`phase-0/research/visual-v3/ramp/reference-audit.zh.md`、`final-inventory-addendum.zh.md`、`coverage-ledger.json`；`phase-0/research/visual-v3/linear/audit.zh-CN.md`、`coverage-matrix.md`、`ledger.json`。Ramp 61 个唯一 section；Linear 93 张实际查看图片。不同 capture 的成员关系仍未验证；研究覆盖不是目标65张的完成率。c224 只有历史主任务 ID 指针与外观支持，不是本轮 AX 归属确认。

参考仅抽象可观察模式。Ramp 的白底点阵 hero、深绿编辑章节、蓝渐变版本并存；不能归纳为“只白底黄按钮”。Linear 有列表、完整详情、Inbox、设置等不同结构；不能把 Inbox 的并排详情强制用于全部业务页面。原生 Mobbin 图片未下载、未重新分发；下列链接供核对原始模式，capture family 全部 unknown。

## 2. 品牌基础

**定位提案**：把品牌与创作者协作中的要求、作品与结果呈现清楚。语气直接、具体、可验证；不用未经证明的收益或增长叙事。标题例：“让好内容，有清楚的下一步。”对象页标题必须是具体作品名“水瓶日常使用演示”，不能用营销标语取代。

**品牌表达**：大留白、清晰大标题、少量有目的的品牌色、真实使用场景。**应用表达**：连续工作面、对齐的元信息、适度密度、可靠状态与恢复路径。两者共享 tokens，但不共享所有字号和构图。

参考：[Ramp 白底产品叙事](https://mobbin.com/sites/sections/c224c647-a876-44fc-ad18-ac01acee3004)、[Linear 列表](https://mobbin.com/screens/9ec39891-cdbb-4d57-b0c6-de43f82c5f4e)。从前者观察留白与主次，从后者观察导航与对象密度；以上定位及数值不是来源原文。

## 3. 字标与命名

使用文字 **Wringy**，大写 W，其余小写；保留原拼写，不附造型 W，不借用 Ramp 或 Linear 标识。当前是 Arial Bold 字标排版提案，未作专门字形设计、商标检查或光学校正。

净空：四周至少一个字标小写 x 的高度；不要让摄影主体、边线或按钮侵入。数字使用建议最小24px，印刷最小7mm。浅底用 ink，深森林色上用白色。不得压扁、拉伸、加阴影或使用酸柠黄细字标。以上清空/尺寸属于独立提案。

## 4. 颜色角色与对比

共用设计数值源为 `tokens.json`；运行 `generate-tokens.py` 生成 `tokens.css`。严禁只改 HTML 表层色值后遗漏源文件。

| Token | 提案值 | 用途 | 禁止混用 |
|---|---|---|---|
| canvas | #FFFFFF | 主工作面、清晰品牌页 | 不代表只能白底 |
| surface | #F6F6F3 | 次级背景、中性选中行、说明块 | 不以浅底单独表示审核结果 |
| ink | #171A14 | 标题、正文、深色行动 | 不用大面积黑色掩盖层级 |
| citron | #E4F222 | 主行动、品牌特色章节 | 不表示付款、资格或成功 |
| forest | #173D2A | 编辑章节、图表首序列 | 不是所有应用页的默认背景 |
| line | #E1E3DC | 装饰分隔 | 不做输入框或焦点唯一边界 |
| secondary | #5C6258 | 辅助文字、关键控件边界 | 不再降透明度用于必要信息 |
| error | #A52A2A | 错误文字和边界 | 同时说明问题与恢复动作 |
| success | #24623E | 成功文字/图标 | 必须写明是哪种成功 |
| focus | #3658A4 | 3px外描边、3px间距 | 不用仅改变背景来替代焦点 |

后3个语义值为本稿新提案，用深色保证白底可读性；非 Ramp/Linear 提取值。酸柠黄上使用 ink，深森林上用白字。对比测量保存在 `contrast-report.json`，按 sRGB 相对亮度计算；正文目标至少4.5:1，非文本关键边界目标至少3:1。浅分隔线不能通过关键边界阈值，因此只作装饰；输入边框使用 secondary。白字酸柠黄组合禁止。

背景按沟通角色变化：活动说明用白底；编辑故事可用森林；特色行动可整块酸柠黄；真实工作区中性选中。参考：[Ramp 深色博客](https://mobbin.com/sites/sections/18a650ac-b4bc-41cd-a13f-490d8760c778)、[Ramp 品牌色整块](https://mobbin.com/sites/sections/c81b8b72-d3eb-4319-af18-711417e238cb)、[Linear 中性列表](https://mobbin.com/screens/9ec39891-cdbb-4d57-b0c6-de43f82c5f4e)。

## 5. 中英文字体、栅格与间距

拉丁字形优先 Arial / Helvetica；中文优先 Noto Sans SC，缺失回退 PingFang SC / sans-serif。本次将项目已有 Noto Sans SC 与 OFL 许可证复制到 assets，并在自包含 HTML 中嵌入字体、CSS、脚本、图片和图标。拉丁字形使用系统 Arial/Helvetica，跨平台仍可能存在微小差异。

| 角色 | 字号/行高提案 | 用法 |
|---|---|---|
| 品牌展示 | 56 / 1.2 | 短句，约9–16汉字每行，避免压缩字宽 |
| 品牌页面标题 | 40 / 1.3 | 一页一个核心论点 |
| 对象页标题 | 32 / 1.4 | 具体活动/作品名称 |
| 模块标题 | 24 / 1.4 | 不与正文争抢 |
| 品牌正文 | 18 / 1.65 | 中文较宽松，长文限宽 |
| 应用正文 | 15 / 1.5 | 操作队列与字段；密集信息不使用营销字号 |
| 注释 | 13 / 1.5 | 来源、概念图说明；不隐藏关键状态 |
| 手机标题 | 30 / 1.3 | 320px宽适配 |
| Deck 聚焦标签 | 32 / 1.35 | 缩入幻灯片仍可读 |

间距序列4/8/16/24/32/64；品牌最大1280、12栏、24栏距；长文最大720；设置表单420；创作者步骤800；侧栏200、属性260（桌面）。这些是原型布局提案，不是从静态参考测量的像素值。标题与内容先靠间距形成关系，分隔线其次，容器最后。来源：[Ramp 标题与故事](https://mobbin.com/sites/sections/8d5e762c-77e0-4cec-b386-4e285906f921)、[Linear 设置结构](https://mobbin.com/screens/aa0b9e71-c5a0-4245-b30a-ee5059de6235)。

## 6. 摄影、构图、图标与图表

摄影使用本项目原创生成图 `creator-studio.png` 与 `bottle-craft-detail.png`，来自投资者材料目录，经授权复制。每处可见使用标注“概念场景，非真实客户”；资产来源详见 `asset-origin-manifest.json`。不呈现为真实创作者、客户、业绩或产品实拍。水瓶无品牌。自然侧光、手部与产品的关系、适量场景背景优先；不得裁掉动作核心或用失真界面贴图假装产品证据。

品牌故事可用照片/纯文字章节交替；应用截图保持一个完整任务焦点，避免层层悬浮。deck 聚焦导出主动隐藏导航和摄影，只保留要求、提交和状态，避免在小尺寸重复整屏。参考：[Ramp 真实场景故事层级](https://mobbin.com/sites/sections/8d5e762c-77e0-4cec-b386-4e285906f921)。

图标：复用 design-v2 的 Tabler v3.34.1 outline SVG（“v2资产”指旧设计目录，不是图标版本2），MIT 授权与版权全文见 `THIRD-PARTY-NOTICES.md`。20/24px，描边1.75，图标+文字；装饰图标 aria-hidden；只有图标的按钮必须有可访问名称。不手绘替代商业logo，不把图标当唯一状态信息。来源：[Tabler 原始版本](https://github.com/tabler/tabler-icons/tree/v3.34.1/icons/outline)、[Ramp 非卡片目录](https://mobbin.com/sites/sections/bc483029-6ba0-43c1-b8b8-902ad8297853)。

图表：当前仅3个模拟对象的分类条形，不是增长或收入。零起点、直接数值、明确分母，2个待审核/1个发布前通过；颜色之外保留文字。不使用付款绿色面积暗示收入。时间序列需真实日期与单位；缺失数据标缺失，不补零。交互 tooltip 不能承载唯一信息。这里是 Wringy 独立提案，未声称 Linear 财务图表依据。

## 7. 布局契约

| 场景 | 结构 | 主对象/动作 | 窄屏 |
|---|---|---|---|
| 活动概览 | 场景与要求双栏 | 活动名、拍什么、提交什么、查看要求 | 场景后要求，顺序不变 |
| 紧凑审核队列 | 连续行、搜索、筛选 | 对象标题、活动、当前审核状态 | 减少次要字段，不缩小全部文字 |
| 完整作品详情 | 大正文＋右属性 | 作品名、内容、审核记录、四个状态 | 属性移到正文后 |
| 创作者进度 | 居中单列步骤 | 当前步骤只有一个主动作 | 天然单列 |
| 设置 | 限宽表单 | 字段标签、说明、输入、保存反馈 | 单列满可用宽度 |
| 属性 popover | 锚定短菜单 | 修改一个演示属性 | 保持边界，不变成全屏详情 |
| 筛选 popover | 条件＋清除入口 | 改变可见集合，不改业务状态 | 保留已选条件 |
| 审核说明 modal | 遮罩＋独立表单 | 输入、取消、保存 | 最大宽度为视口减32 |

来源：[Linear 队列](https://mobbin.com/screens/9ec39891-cdbb-4d57-b0c6-de43f82c5f4e)、[完整详情](https://mobbin.com/screens/6e105b56-a616-497c-87bc-70fdeaf31048)、[设置](https://mobbin.com/screens/aa0b9e71-c5a0-4245-b30a-ee5059de6235)、[属性](https://mobbin.com/screens/744b87f4-4e13-488a-9338-2ca18b39bef1)、[创建弹窗](https://mobbin.com/screens/9ae1ad02-5e59-4079-9eba-21589c0fe211)。静态截图不能证明键盘交互；本稿的键盘契约独立实现与验证。

## 8. 组件状态与行为契约

| 组件 | 常态/选中 | 焦点/操作 | 加载/错误/禁用 | 当前展示范围 |
|---|---|---|---|---|
| 主按钮 | citron＋ink | 44px最小高，明显焦点，Enter/Space | 处理中保留宽度并说明；禁用不作为唯一解释 | 常态/悬停/焦点演示；网络处理中未接服务 |
| 次按钮 | 白底＋secondary边框 | 与主按钮相同 | 恢复动作保留明确文案 | 取消/筛选/重试演示 |
| 输入 | 可见标签，不只placeholder | Tab可达 | 必填错误保留值；错误与字段关联 | 原生required验证；独立错误样例 |
| 队列行 | 连续分隔线，中性选中 | 实际button键盘可达，aria-pressed | 无匹配另显示，不替换为首次空态 | 3行筛选/选择已实现 |
| 属性浮层 | 当前属性与选择项 | 原生popover，Escape关闭 | 无权限状态需业务契约 | 本地演示状态不会改变真实作品 |
| 模态框 | 一项任务、一组主次动作 | 初始输入焦点、Tab循环、Escape关闭并还原焦点 | 表单留值；不在失败时关闭 | 本地备注保存，不写服务器 |
| Toast/反馈 | role=status礼貌播报 | 不劫持焦点 | 关键错误保留在页面 | 设置保存状态文字，刷新重置 |
| 状态标签 | 文字明确状态对象 | 不仅颜色、图标 | 未知显示未知，不能当失败或付款 | 四种事实分开显示 |

禁用与加载仅定义契约，不冒充已经覆盖所有服务边界。实际产品未来必须验证重复提交、防重复操作、权限、断网、超时、撤销与恢复；本次是视觉原型，不做业务上线承诺。

## 9. 业务语义与空态

固定样例源在 tokens.samples：活动“日常好物演示”，无品牌随行水瓶，示例创作者 A，作品001/002/003。唯一作品主标题“水瓶日常使用演示”。示例数量3，待审核2，发布前通过1；所有数字均是模拟对象数量。奖励金额未批准，本稿不发明金额。

四个状态必须独立：发布前审核通过（可进入示例发布步骤）；最终审核通过（最终检查结果）；奖励资格已确认（资格判断）；银行实际付款已确认（实际资金记录）。前三项不得导出最后一项。当前作品001仅发布前通过，最终审核尚未开始、资格尚未确认、尚未付款。产品流程顺序也是提案，不代替模型审批。

空态分为：首次没有对象 → 解释用途/创建入口；无匹配 → 保留条件/清除筛选；尚未选择 → 集合存在/选择一行；正在读取 → 保留空间/加载说明；读取失败 → 原输入保留/重试；字段错误 → 就地说明修正方法。前3种参考：[首次空态](https://mobbin.com/screens/5273571d-4f58-410a-97a0-f6018dc8b80f)、[筛选无结果](https://mobbin.com/screens/90b0ca17-b70a-425c-b28b-ce934231b2b9)、[未选中](https://mobbin.com/screens/18c6955a-c42f-4cc1-9aa2-0276456720fb)。字段错误参考：[必填错误](https://mobbin.com/screens/5c68cc35-0d93-47ba-b27e-ed4efe90b75c)。加载、网络错误、重试、无权限未找到足够 Linear 图像，均为独立设计，不伪装已有参考覆盖。

## 10. 响应与动效

320：单列，标题30，主要触控目标44高，侧栏不挤压正文；768：依内容最小宽度确定两列，设置仍限宽；1440：品牌宽裕、应用按任务分区。断点480/800是本稿提案；不是从iOS图推导web断点。原始 deck PNG 是固定导出画布，不应拿来验证真实网页响应；showcase 的实际队列、表单、弹窗才是本地交互演示。

普通反馈120–180ms、ease-out；不使用滚动劫持、自动播放、强制大幅漂浮。prefers-reduced-motion 下移除装饰运动，状态变化仍可理解。未从静态 Mobbin 截图推导动效时长。

## 11. 投资者材料适配

一页一个主张，一张主要证据图。品牌可用大图和留白；产品解释页优先 deck-activity-focus / deck-review-focus，避免整屏缩小后字体难读。三张完整产品 PNG 用于指南或可放大查看。正文、图例与来源不压到不可读；不要使用真实客户 logo、未经验证 KPI 或把概念图当案例。这里是按照本次“YC clean deck”方向作的 Wringy 排版提案，不宣称 YC 官方视觉规范。

## 12. 交付与已知限制

`showcase.html` 自包含本地预览，含10页指南与实际交互样例；`Wringy-visual-guide-v3.pdf` 为固定10页；`assets/` 包含原创照片、5张产品导出、Tabler图标及验证截图。数值以 tokens.json 为准，CSS 为生成物；构建步骤见 README.md。检查结果以 verification.json、contrast-report.json 与逐页渲染为准。

未解决边界：精确capture归属未知；没有官方品牌字体/颜色源码；系统拉丁字体可能跨机略有不同；真实服务、交易、权限、上传、移动原生、付款凭证完全未实现；模型与生产规范未批准。允许将本稿用于有明确边界的独立 Wringy 设计推进，不需要等待无法取得的官方完整目录。

共用数值与本地展示几何的边界：tokens 管理色彩、字体层级、间距序列、圆角、控件尺寸、主要布局宽度、断点、导出尺寸、动效和固定样例。模板中的局部图片裁切、页面页眉/页脚留白和演示注释排版是本指南的展示几何，不作为产品共用 token。此界限避免把每个印刷坐标误称为应用规范。
