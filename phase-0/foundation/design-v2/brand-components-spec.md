# Wringy 品牌与设计系统 v2

2026-09-10 · 可审阅设计交付

## 设计决定与适用范围

用户已明确否定 v1 钴蓝方向，并指定 Ramp 的暖白页面用于品牌风格，Linear 用于应用组件与工作区。此稿落实该方向。具体色值、排版、字标和尺寸是 Wringy 独立适配建议，不是 Ramp 或 Linear 官方提取的设计资产，也不冒充正式品牌批准。

本次授权为可审阅设计制品。交付仅在 `design-v2/`；没有更改历史 v1、生产应用、后端、付款、上游商业规格或只读参考文件。用户本轮对方向、清单语义、canonical 金额和打印分页的修正，记录在本稿末尾。

已核对直接上游：[原品牌稿](../brand-design-v1.md)、[原设计值](../design-tokens-v1.json)、[产品需求](../prd-v1.md)、[产品命题](../product-thesis.md)。它们存在，但产品需求和命题均未批准；没有客户验证材料、已选支付商或真实交易证据。本稿延续其业务边界，不用视觉完成度补成业务批准。关闭这些缺口需产品命题所述访谈和原型实验、资金可行性调查及 Belcort 范围评审；不是本次画面制作能关闭的事项。当前为文档镜像目录，不把工程仓库或测试流水线当作已存在。

成功标准：品牌明显呈现暖白、黑字、黄绿操作与克制构图；后台包含紧凑侧栏、顶栏、筛选、分组作品行、右详情；创作者在窄屏仍看清金额、期限与下一步；规范、展示和导出源于同一 tokens；审核阶段不混淆为奖励或付款；桌面和手机无整页横向溢出。

## 品牌主张与语气

主张沿用“让好创作，有清楚的回报。”，英文表达为 “Good work. Clear rewards.”。清楚指要求、审核和奖励记录可理解，不承诺获得收入、播放量、销量或即时到账。服务对象是品牌和创作者，首发活动类别仍是邀请制按获批帖子付费的候选方案，未获商业批准。

语气直接、尊重、有具体下一步。例如“请填写以 https:// 开头的完整作品链接”，比“格式错误”更可执行；“预审通过，可发布”比“成功”更准确。禁止“轻松赚钱”“保证爆款”“余额已到账”等无证据承诺。界面不用内部政策说明反复打断操作；全页一次简短概念示例说明，业务影响只在相关位置解释。

中文是本轮审阅语言。未来试点产品语言仍按 PRD 待定，不声称已经具备三语产品。所有人物、活动、日期、金额和作品均为样例，不是客户、业绩或已完成订单。

应用参考来自本 worker 的 Mobbin MCP 实际图片检查：[Linear 详情与属性](https://mobbin.com/screens/beb9d6b3-ec34-46d7-9332-320fcb32a338)提供左导航、列表、详情正文、右侧属性结构；[Linear 评论菜单](https://mobbin.com/screens/73891735-c12b-4ed3-bd7f-fc6bc3c52228)提供紧凑浮层菜单、分组操作与次级层级。主任务另提供的两张 Linear 参考保留在 [sources.json](sources.json)，明确区分来源，不声称自行检查了那些图片。

Wringy 的适配是“品牌留白 + 应用密度”。展示部分视觉变化 5、动效 2、密度 3；后台密度 7。没有复制 Ramp logo、截图装饰、官方字体或 Linear 标志。色彩和尺寸由本稿独立制定。

## 字标规范

小写 `wringy` 用紧凑无衬线粗体排版，结尾为独立小方形句点。保留 g、y 自然下伸，不裁切；字距由 `letterSpacing.wordmark` 控制。方形句点可使用 Citron 填色及 Ink 描边。它是 Wringy 的独立排版字标，不采用 Ramp 的图形语言。最小建议宽度 76px；安全区为半个字标高度。纯文字场景写正式名称 Wringy。

默认白/暖白背景、近黑字标。单色应用把句点也设为 Ink；不反转整个展示页制造另一套主题，不加渐变、外发光、拉伸、描边字或倾斜。截图采用系统字体，未捆绑商业字体文件；不同系统可能回退，字形像素不保证一致。该排版示范不是商标注册结论或已完成字体授权采购。

## canonical 设计值与生成关系

[tokens.json](tokens.json) 是本目录视觉数值和共享业务样例的唯一来源。tokens 是可复用的命名值，例如 `color.accent`；语义名称说明用途，例如 `semantic.actionPrimary` 指向 `color.accent`。禁止在单个页面另选颜色，或在 deck 中重新猜主色。

顶层结构：`meta`、`color`、`semantic`、`font`、`fontSize`、`fontWeight`、`lineHeight`、`letterSpacing`、`space`、`radius`、`border`、`layout`、`breakpoint`、`motion`、`shadow`、`zIndex`、`icon`、`state`、`format`、`example`、`print`。字段保留 v1 常用命名以便下游消费，但不复用 v1 配色。

`build.py` 读取 JSON，把视觉分组生成 CSS 自定义属性，把语义引用生成别名；`showcase.html` 内嵌完整 JSON 与 SHA256 指纹，离线无需读取邻近文件。`tokens.css` 是同一生成快照。`example.rewardMinor` 是 MYR 最小货币单位，生成统一的 RM 显示金额；活动与品牌文字也通过模板占位生成。静态画面、原稿确认、最终审核确认及创作者视图同源，不维护多个金额字符串。货币格式只适用于当前 MYR 样例，不是支付计算实现。

更新：修改 JSON → 运行 `python3 build.py` → 本地 renderer 检查 → 更新截图/PDF/evidence。不要修改生成 HTML 的 token 区、deck 里的副本或 screenshot。组件结构、单个内容样例不是完整数据库模型；展示中的状态词汇不替代 PRD 转换规则。

## 色彩标准

| 用途 | token | 规则 |
|---|---|---|
| 页面 | canvas | 暖白阅读底色 |
| 工作区 | surface | 白色主工作面 |
| 品牌构图 | composition | 暖灰容器，少量用于展示，不变成每层卡片 |
| 主文字 | ink | 标题、金额、主要内容 |
| 辅助文字 | muted | 时间、说明、标签；不降低为不可读灰色 |
| 强调操作 | accent / hover / pressed | Citron 黄绿，黑字；一操作区域一个主动作 |
| 选中 | accentSoft | 低浓度黄绿背景，配合边缘线或文字粗细 |
| 分隔 | line | 仅装饰/组织，不承担输入控件唯一边界 |
| 控件轮廓 | controlBorder | 输入、次按钮等必要轮廓 |
| 焦点 | focus | 深橄榄色，2px 轮廓，3px 间隔 |
| 成功 | positive / positiveSoft | 已完成的明确阶段，带文字 |
| 注意 | warning / warningSoft | 待审、需修改、需查证 |
| 错误 | negative / negativeSoft | 输入或读取失败，附原因与下一步 |

不使用钴蓝或蓝色渐变。绿色只表示实际完成状态，未核对清单用中性图标；即使一旁写“待核对”，也不得用绿勾产生完成错觉。黄绿色亮度高，不用于白字正文；本稿按钮使用 Ink，实测主按钮对比 13.18:1。完整配对结果见 evidence。

## 排版、间距与图标

字体采用 Helvetica Neue / PingFang SC / Microsoft YaHei / Arial 回退。展示 76px，手机 42px；章节 36px，阅读 16px，应用正文 14px、行标签 13px、元信息 12px。展示行高约 1.08，标题 1.25，正文 1.6。强调靠字重和位置，不靠彩色长段或同时混入衬线。金额采用等宽数字，币种完整呈现；未知显示原因，不拿 0 代替。

间距以 4px 标尺递增。宽页面最大 1320px；常规边距 40px，手机 20px；章节一般 64px，手机 40px。大标题与紧凑列表可共存，但正文不压到脚注大小。圆角按用途统一：控件 6px，面板 10px，徽标 4px，头像全圆。细线 1px；只给浮层和品牌构图轻阴影，不给每个信息块投影。

图标采用 Tabler Icons v3.34.1 outline，18px，紧凑场景 16px，描边 1.5px。同一家族，不混 emoji。装饰 SVG `aria-hidden`；纯图标按钮有可访问名称。图标不承担状态唯一含义，旁边保留文字。原 SVG 保存在 assets，HTML 内嵌调整尺寸/描边；许可见 [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md)。

## 工作区与响应式

桌面为 196px 左侧栏 + 流动主区；主区 48px 顶栏，中央队列与 284px 右详情。左侧显示当前组织和审核身份，不把财务动作混入品牌审核。队列用原稿预审/最终审核分组，行内作品名、创作者、版本、日期。主栏不铺业务图表或虚构增长数据。实际展示行包含两行信息，高于单行 44px 基准，保持可读。

Tabs 用于审核阶段；筛选只收窄状态；搜索只搜索样例标题/创作者。右详情显示明确审核层级、规则版本、截止/提交时间、条件金额、待核对要求与版本历史。切换列表项更新详情；筛选不会自动替用户做决定。详情保留选择项上下文，若选择暂不在筛选结果内，不抹去其内容。

1023px 及以下右详情移到队列下方并可分两栏；639px 及以下单栏，侧栏由菜单按钮展开。手机保留完整日期在详情，隐藏列表重复日期。标签页不横向拖出页面；长字段换行，输入宽度受容器约束。

创作者画面不是缩小桌面：一栏、明确身份、活动与固定奖励、原稿状态、发布与链接提交、底部两入口。触控目标至少 44px。它只代表自己的受邀合作，没有公开市场或其他创作者私人资料。390px 和 320px 实测无整页横向滚动。720 CSS px 的 reflow 测试近似 1440px 下的 200% 放大空间；不是原生浏览器缩放或完整辅助技术审计。

## 组件契约与状态

| 组件 | 结构与已展示变体 | 交互与实施要求 |
|---|---|---|
| Button | 主/次/文字/危险/禁用；36px 桌面、44px 手机 | hover/pressed/focus；禁用有原因；加载期间防重复操作 |
| Input | 标签、值、辅助、错误 | 标签不可只用 placeholder；错误关联字段；失败保留输入 |
| Select | 原生选择器、可见标签 | 示例活动平台只有一个值，说明其由活动指定；不伪造多平台业务 |
| Tabs | 明确选中项、细下划线 | 左右键、Home/End、Tab；aria-selected、tabpanel 关联 |
| Filter | 按状态的紧凑浮层，单选组 | 按钮标明展开；Escape/外侧点击关闭；搜索与筛选可同时作用 |
| Grouped rows | 分组标题、数量、作品行、版本、时间 | 整行为按钮；选中与 hover 分开；空筛选有清除入口 |
| Detail | 阶段、作品、属性、要求、历史 | 内容阶段与奖励阶段分开；待核对只用中性清单图标 |
| Badge | 中性/注意/成功/错误 | 完整文字；不依靠颜色或圆点；不把预审成功标为已付款 |
| Dialog | 标题、对象、影响、取消、明确动作 | 原生 dialog；初始焦点、循环 Tab、Escape、关闭后返回触发器 |
| Empty | 说明当前范围、原因、下一步 | 无作品与无搜索结果分开；不将无权限称为空列表 |
| Loading | 保留行结构的骨架与文字 | 不显示零作品或零金额；减少动效时静止 |
| Error | 明确失败、保留输入、重试 | 无责备；可恢复示例重试后显示已载入，不产生业务记录 |
| Creator submission | 活动上下文、HTTPS 作品链接、提交 | 本地格式校验；只验证示例 URL 格式，不声称核实真实发布内容 |
| Activity | 时间、版本、动作 | 历史记录保留，不覆盖前版决定；此处全部为静态样例 |

HTML 提供真实的本地展示交互，但不写业务数据、不联接账户或支付。审核确认按钮显示决定预览并保留原样例；创作者提交仅在本页更新示例状态。刷新恢复样例。危险按钮场景没有附件可删除。无需反复在每个按钮上标“未实现”，范围由一次概念说明及本规范说明。

## 业务状态与权限表达

唯一业务规则来源仍为 PRD。候选第一模型：邀请制、单活动指定一个平台、原创内容先预审、创作者自行发布、最终人工审核后按合格帖子计算固定奖励。不是 CPM、按观看量或无需发布的素材采购。样例金额不构成报价。

四层事实不可合并：原稿可发布 → 最终作品获批 → 奖励符合付款条件 → 银行出款证据。原稿预审通过不产生奖励；最终通过可记录奖励义务但不等于付款；服务商账户入账与银行出款分别说明。金额未知、付款未知、失败、暂停、冲正保留各自原因，不删除已有义务，不靠重新点击演示支付修复未知结果。

品牌审核员可处理所属品牌授权活动的内容，不能看到银行资料或发起付款。创作者只访问自己的邀请和资料。运营处理风险不自动撤销奖励；财务经办与复核分开。实际权限必须由未来应用服务端保证，本稿的界面展示不是权限验证。

异常文案标准：邀请失效说明已过约定期限；活动暂停说明新增参与暂不可用、原有记录保留；名额满不能伪装仍可加入；作品需修改关联原规则与版本；链接失效要求补充证据；无权限使用中性说明，不透露其他组织的活动名称。未展示的财务操作、上传、申诉和角色切换不冒充已覆盖完整页面设计。

## 动效与可访问性

仅用短暂反馈：120ms hover/pressed，180ms 为状态过渡上限；不做循环漂浮、数字跳动或成功庆祝。`prefers-reduced-motion` 下关闭过渡与自动平滑滚动。金额变化不滚动播报，错误和付款核对不使用庆祝语气。

验证目标是普通文字 ≥4.5:1、大文字和必要控件/焦点 ≥3:1；色弱用户可通过文字理解。HTML 有 skip link、真实按钮、标签、关联错误、命名导航、tablist、dialog 与 live status。对话框 Tab 在首尾循环并支持 Escape，关闭回到触发器。焦点样式不依赖鼠标 hover。不是完整 WCAG 认证，屏幕阅读器实机、跨浏览器、不同字体系统和真实异步上传仍未覆盖。
