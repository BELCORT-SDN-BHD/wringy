## 商业闭环

品牌希望让已有内容或产品触达更多相关受众，提供奖励预算、素材授权、目标人群、渠道、内容限制与计酬规则。创作者参与并发布内容，按合格结果获得报酬。Wringy拟提供活动与创作者匹配、规则执行、效果核验及奖励结算记录，从符合条件的业务量获得服务收入。

品牌采购的是约定的传播结果。播放不等于独立人数、点击、订单或销量，不能把其中一种直接当成另一种。活动须先定义统计窗口、有效播放口径、受众条件、奖励上限及异常处理。平台数据权限、核验能力、资金路径未落实，不能宣称已经全自动或零作弊。

## 统一算例，全部为说明假设

为把创始人图中的百分比说清，本稿暂用“品牌在已确认创作者奖励之外另付平台费”。不从创作者奖励再扣一次。15%是代理为演示设置的假设，尚非定价决定、Whop费率或行业平均。

| 项目 | 算例 |
|---|---:|
| 创作者奖励预算上限 | RM10,000 |
| 每1,000次合格播放奖励 | RM5 |
| 全额赚取预算所需合格播放 | 2,000,000 |
| 单个创作者50,000次合格播放奖励 | RM250，受活动上限和规则约束 |
| 本例已确认创作者奖励 | RM10,000 |
| 平台服务费率 | 15%，奖励之外另计 |
| Wringy服务收入 | RM1,500 |
| 品牌总支出，未计税 | RM11,500 |
| 单场可变履约成本占位 | RM600 |
| 单场活动获取／转介佣金 | RM150 |
| 单场贡献，固定费用及独立品牌获客费前 | RM750＝RM1,500−RM600−RM150 |

单场贡献是服务收入扣除可变履约成本及活动佣金后的余额，尚未扣固定费用及独立品牌获客费，不能称净利润。RM600由审核支持300、数据100、支付150及异常损失50组成，全部是估计而非报价；审核成本覆盖所有提交（含拒绝、异常及申诉），不能只按已获奖励内容计费。RM150活动佣金与独立品牌获客费分开：财务模型将M5首批品牌获客归入RM50,000启动池，M6起新增及流失替补品牌按RM1,500／品牌另计，已纳入公司现金流，不与启动池、活动佣金或固定销售工资重复计算。若可变履约成本与活动佣金合计达到RM1,500，单场贡献归零。

15%是奖励外加服务费率；服务收入占品牌总支出的13.04%是另一比例；RM750／RM1,500＝50%是固定费用及独立品牌获客费前的贡献率。毛利还需计入固定履约成本：按财务模型20场／月示例，销售成本为RM600×20＋RM2,000，毛利RM16,000、毛利率53.33%，分母为平台净服务费收入。固定履约RM2,000已经属于每月固定总支出RM17,000，不得重复扣除；毛利率随活动量变化，税后净利润未知。完整公式、公司累计回本、获客回收及敏感性只在上述财务模型维护。

未赚取的奖励预算不产生本例平台费，退款或取消后的费基须相应调整。奖励代转款不计平台收入与成本仅为代理规划假设；实际主要责任人／代理人及总额／净额收入确认仍待合同判断，不代表Wringy可自行托管资金。

规模情景：每月100个活跃付费品牌×每品牌2场×每场RM10,000已确认奖励×15%=RM300,000月服务收入。对应每月200场、RM2,000,000创作者奖励，按RM5／千次意味着400,000,000次合格播放需求。这只是模型算式，不是预测、目标获批或市场规模。须验证品牌预算、付费频次、创作者供给和计量吞吐，不能只展示收入而隐去所需业务量。

## 第一阶段之后的收入机会

先验证品牌持续采购及创作者持续交付。再探索让这些创作者经营店铺、课程、数字产品和会员，候选收入为交易服务费或经营工具订阅。支付是支持交易的能力，能否另收净服务费取决于服务商成本、合同及准入，不能将支付通道代收费全部当Wringy收入，不能对同一笔交易重复计算两种佣金。

复购、供给增长和跨业务转化均为假设，不是已形成网络效应或护城河。首批关注实际复购、每场可变成本、合格结果交付率、争议损失、品牌获客成本与回收时间。长期完整范围仍见[产品总图](product-map.md)。
