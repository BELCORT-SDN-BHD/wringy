## 怎么使用

创始人：先试按钮、表单错误与重试、弹窗和奖励状态，再通过组件目录查看每个组件的详细规范。这里不会发送表单、审核作品或处理资金。

Belcort：先读handoff，再使用tokens与catalog。目录里的状态是设计要求；示例代码和截图不能代替真实服务、权限与异常流程验收。

## 基础值的唯一来源

[tokens.json](tokens.json) → generate-tokens.py → [tokens.css](tokens.css)。保留已认可的白／酸柠黄／深色方向，新增语义层与组件映射。颜色、尺寸和交互参数是Wringy的独立提案，不宣称取得Ramp或Linear官方设计源文件。

## 交付边界

设计规范、视觉样例、交互演示和生产实现分别记录。全平台规划不等于全平台后端已实现；模拟数值不等于正式费率或实际业绩。浅色主题为本版范围，完整暗色主题与原生移动组件包未制作。

Creator Rewards优先展示，长期完整12板块仍保留。首发计酬、数据权限、预算预留、风险与资金规则尚未冻结，见handoff的决策表。产品默认语言、正式字体采购、专门标志设计及实际设备发布测试不由本地演示替代。
