# 设计系统 v2 验收记录

日期：2026-09-11。用户本轮指令为组件、状态及设计系统严格采用 Linear＋shadcn，仅沿用既有配色。此记录针对本地设计系统，不是产品上线验收。

## 来源与视觉检查

- 配置为官方 Radix/Nova，实际生成 61 个 UI 文件；另有 Date Picker、Data Table、Typography 三项官方组合/排版指南入口。
- [源码差异报告](app/provenance/verification.json)逐文件比较官方快照，并验证全局 CSS 除浅色颜色变量外保持一致。
- Linear 用于页面信息层次和工作区模式，证据见[来源合同](reference-contract.md)。截图不能证明其内部源码或所有交互。
- 主任务打开本地预览，检查按钮、桌面数据表格；通过界面操作验证 Dialog 打开时聚焦输入、Escape 关闭后回到触发按钮。

## 复核决策

| Before | After | Why |
|---|---|---|
| v1 自定义组件几何、状态皮肤与动效 | v2 采用官方生成源码，颜色在全局变量映射 | 执行用户最新范围，不继续维护第三套组件体系 |
| 只验证全部入口能显示 | 加验命令弹窗真实打开、选择、关闭和返回焦点 | 挂载通过不能证明浮层内组件正确组成 |
| 命令弹窗缺少 Command 根组件 | 使用官方 Command/Dialog 组合修正，最终结果见浏览器报告 | 避免打开后运行错误，保留官方焦点行为 |
| 示例导航链接占用组件目录的 URL 片段 | 本地选择保持当前示例，最终结果见浏览器报告 | 示例操作不应意外退出当前组件 |
| 单滑杆将名称放在非焦点根节点 | 使用可验证命名的官方范围示例；单滑杆限制另记 | 不修改官方内部源码或通过 DOM 补丁伪造接口 |
| SidebarInset 内再嵌 main，URL 解码未处理无效片段 | 保留单一主要区域；无效片段退回默认入口 | 修复组合层语义和导航恢复，不修改组件源码 |

## 验证依据

自动检查以[浏览器报告](output/browser-verification.json)为准；最终收口须检查 result 为 passed，并核对最终导出时间与应用版本一致。构建、类型、代码检查和来源检查由应用实施记录提供。

业务领域仍引用[独立规则提案](../design-system-v1/domain-states.md)。之前对这些规则的跨厂商只读审查与修正见[v1 审阅记录](../design-system-v1/review.md)；它不替代本轮 UI 验证。官方没有提供的专业编辑器、播放器等能力继续在组件映射中明确列为缺口。

未宣称每个上游属性排列、所有浏览器、真实移动设备或读屏软件均已验证；未接入生产账号、审核或资金服务。
