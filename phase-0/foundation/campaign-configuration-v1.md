## 商家怎样建立活动

2026-09-14更新：[核心默认配置已确认](campaign-defaults-v1.md)，以该文件的批准范围为准。下表早期“数值待定／分配尚未选定”描述由该确认覆盖；未展开的边界规则仍待定案。

**配置方式已确认（2026-09-14）：平台提供默认配置，商家可调整。** 下表中“金额承接核心默认／必须填写／尚未选定”等表示当时默认值尚待拟定，当前核心默认已确认，以默认源为准，不代表最终产品要求商家从空白开始。最低门槛、费率、单条封顶、时间及可支持的预算分配选项应提供建议值或默认选项；商家发布前可修改并预览效果。与核心默认一致的值按源记录承接；额外示例与边界仍待批。系统校验门槛与上限是否兼容、数据是否可验证；规则变更需保留版本与生效范围。

1. 填写推广目标、产品与授权素材。
2. 选择发布平台、内容语言及目标受众。
3. 写清内容要求、计酬方式、奖励池与时间。
4. 运营核对数据能力、授权、预算分配与付款条件。
5. 商家确认费用和规则版本，满足资金条件后发布。
6. 查看投稿与审核结果，完成结算，再决定续投。

首版可由工作人员协助配置，不预设全部自助或自动审核。

## 1. 活动与受众

|字段|选项／填写内容|建议默认|审核与付款影响|
|---|---|---|---|
|基本活动|名称、推广对象、目标、联系人、素材链接|关键资料必填；备注可选|先知道在推广什么、向谁核实|
|发布平台|选择拟支持的YouTube／Instagram／TikTok等|不预选；只开放已验证可接入的平台|各平台数据口径与账号验证分开|
|内容语言|EN／BM／ZH或另行约定|不限制；与界面语言偏好分开|必需语言须在参与前说明|
|目标受众资格|地区、语言及所需证明|不额外限制；限制须有可核实依据|账号受众资格不等于每次观看所在地|
|实际地域计费|全球合格观看；指定地区合格观看|建议不限制地区；仍须验证基本计量能力|指定地区仅在数据许可和精度通过后开放；不能用粉丝地域比例乘总观看代替|

无法按地区计量时，商家可接受全球合格观看并保留受众要求，或暂不开展该方案；不能把“希望触达马来西亚”写成“已验证马来西亚观看”。

## 2. 内容与权利

|字段|选项／填写内容|建议默认|审核与付款影响|
|---|---|---|---|
|内容要求|主题、片长、品牌露出、标签、禁用内容|逐项标“必须”或“建议”；可选项不设硬门槛|不能因没遵循建议而拒付|
|素材与使用权|素材来源、编辑权限、音乐／肖像授权、商家后续使用范围及期限|发布前确认；不默认永久或独家授权|素材获准剪辑不等于商家获得成片全部权利|
|公开保留时间|从何时起、保留到何时；删除／私密处理|必须约定，不套用固定天数|与付款时间分开；违规后果及申诉须预先写明|

Clipping样本活动要求保留90天，但这是该活动规则，不是Wringy默认；同一简报明确标签可选，不能因未标记拒绝。见[登录实测及活动简报](../research/clipping-deep-v2/browser/onboarding-findings.md)。

## 3. 奖励、预算与日历

|字段|选项／填写内容|建议默认|审核与付款影响|
|---|---|---|---|
|观看费率|币种、每1,000合格观看奖励、取整与最低资格口径|核心费率见默认源；发布前确认|明确哪些观看计入，不能按显示总观看直接付款|
|最低申请门槛|最低合格观看数或最低可申请奖励金额；组合关系须明确|创办人确认需有门槛，核心最低金额见默认源；100,000观看仅为额外门槛示例|未达标投稿可追踪但不具备奖励申请资格；金额门槛不是钱包提现门槛。比较边界、达标后门槛前观看是否计酬须明示|
|奖励池／平台费|奖励总额；平台收费基数、费率或金额另列|分别确认，无获批默认费率|奖励不是Wringy服务收入；支付手续费承担方另列|
|单条奖励上限|商家设定每条视频累计最高奖励|创办人已确认封顶方向；金额承接核心默认|达到上限后奖励不再随观看增加，分次领取不重置；仍受活动总预算及分配规则约束|
|预算分配|预留额度、先后顺序或周期分配等候选|按有效申请时间排序已确认；候补通知后重提新排序已批；部分报价次序已于2026-09-15批准|多条同时增长可能超出余额；未解决前不承诺绝不超支|
|投稿期|开放与截止时间、时区|必须填写|截止后能否补交须提前说明|
|计量期|每条观看起算点、结束点、数据来源|必须填写，与投稿期分开|旧观看、延迟回传、私密内容及接口中断须有处理办法|
|申请期限|计量结束后的申请宽限及受阻延展|默认7个日历日已批准，发布前可改正的明确时长|按[默认源](campaign-defaults-v1.md#申请期限2026-09-14已批准)记录截止与通知，不延长计量或清除及时申请|
|最终复核等待期|计量结束后复核时段及异常延长条件|发布前约定，不默认7天|等待结束不等于已支付；暂缓须说明原因和下一次处理时间|

**纯奖励算例，不是批准价格：** 奖励池RM2,000、每1,000合格观看RM5，全部花完对应400,000次合格观看；一条20,000次合格观看对应RM100。前提是全部通过内容与计量核验、符合时间口径、取整不改变结果，且单条上限与预算分配允许。不是独立人数、收入保证；不含平台费及支付手续费。

2026-09-14补充：每条视频封顶方向见[创办人记录](../founder-inputs.md)。例如单条上限RM100，40,000次合格观看按上述费率原可计RM200，封顶后最多RM100；这不等于已审核或已支付。如果活动只剩RM50，两条视频各符合RM100奖励，仍需另行确定预算分配方式。商家允许时跨平台视频独立封顶已批；同平台同ID不重复，跨活动复用仍待定。

最低门槛补充：上述算例还须满足活动最低申请门槛，不能理解为任何低观看投稿都能占奖励预算。待决流程为追踪→达到门槛→申请／自动进入队列→审核→按预算分配→付款；有效申请时间排序已确认；一次申请全部可用奖励及一个待处理已批；其余边界见PRD待决项。发布检查需防止最低奖励门槛高于单条上限等无法达标的配置；余额不足以支付最低金额时如何处理仍须约定。最低门槛减少无效申请，但不单独解决多个达标申请竞争余额的问题。

## 4. 审核、规则变更与付款

|字段|选项／填写内容|建议默认|审核与付款影响|
|---|---|---|---|
|审核分工|商家核对内容；运营核对计量、处理争议；指定奖励批准人|发布前列明负责人及权限|内容合规、观看有效、奖励批准、付款完成分别记录|
|平台底线／申诉|反作弊、侵权与违法内容底线；拒绝理由、证据、申诉入口与期限|商家不能豁免底线；期限须明示|可疑不等于已证实；复审人及结论留痕|
|版本与变更|通用规则、活动规则、周期规则及生效时间|参与时展示并保存版本；变更通知|不得用新增条件追溯拒付；存量投稿如何处理须事先约定|
|资金与退款|谁出资、何时备款、谁付款、支持方式；结案余额及争议款|发布前确认，不默认托管或平台垫款|未用奖励池与已承诺待付分开；退款条件、费用及时间另定|
|结算状态|估计、待审核、已确认待付、支付处理中、已支付、失败／结果未知|有付款凭据才记已支付|结果未知先对账，不能直接重付；退款另记，不混入创作者收入|

## 先决定三件事

- **数据：** 首批平台能提供什么可授权、可复核的数据？地区只能作受众资格，还是足以参与实际计费？
- **预算分配：** 多条投稿同时达到门槛时如何预留、分配、停收并处理延迟数据？商家与创作者须看到同一规则。
- **资金与付款：** 奖励资金由谁持有、何时落实、谁批准及执行付款？未用余额、争议款与失败付款如何结清？
