# Wringy 交付包阅读指南

解压 `Wringy-Phase0-交付包.zip`，从包内本指南开始阅读。包内只保留每份演示选定的最终版本。先用 PDF 阅读；需要修改内容或演示时，再打开同名 PPTX。三份演示分别回答：Whop 怎么运作、Wringy 的商业假设怎样成立，以及 Wringy 应该怎样表达和设计。

本包包含三份中文演示：Whop 学习 64 页、投资与伙伴提案 38 页、品牌手册 30 页。学习文件采用已选 v4，包内文件名不保留历史版本后缀。必要的英文产品名和原始界面保留。

## 读懂 Whop：先抓住三件事

先看谁在付钱、谁在收钱，再看按什么条件支付。例如，创作者按合格播放量取得报酬，与推广者按订单取得佣金，是两种不同机制。

已确认的第 4 版学习演示共 64 页，按 40 页核心内容＋24 页功能附录组织，附录覆盖 168 个稳定功能编号。正文讲机制，附录用中文短说明帮助定位功能；这些编号是本次研究的索引，并非 Whop 对外公布的完整功能清单。

所有标有“教学假设”的 RM 数字都用于理解计算，不代表 Whop 或 Wringy 的实际费率。Content Rewards（CR，内容奖励）的费用还要区分适用主体与条款；不要把 CR 的费率当作 Whop 全平台统一收费。界面示例与现行条款可能来自不同时间，按页内说明和来源阅读。

要继续查证，可在 PowerPoint 的“备注”中查看讲解和来源链接；PDF 适合阅读版面，不一定包含全部讲稿。研究资料包另提供来源链接索引。

## 商业提案：把假设和业绩分开

市场统计是背景证据，经营模型是规划情景，Wringy 的客户数量、活动预算、费率和未来收入仍需验证。交易总额、平台收入、利润与可用现金是不同的数，不能直接互换。

模型保留不同团队、采用速度与预算条件。尤其不要把“每品牌年预算 RM30,000”的市场假设，与隐含更高年度活动预算的经营情景拼成同一条预测。阅读时同时看预算约束与融资需要。

财务资料以 MYR（马来西亚令吉，也写作 RM）计。创作者奖励预算不自动成为 Wringy 收入；首发模型采用品牌直接向创作者付款、Wringy 收取自身服务费的假设。

## 品牌资料：从规范到实际使用

解压后保留文件夹结构，打开 `品牌资料/brand/showcase/index.html` 浏览展示页。它用于理解视觉和组件示例，不代表已经上线的产品。

设计数值以 `品牌资料/brand/tokens.json` 为准。这里的 tokens 是可复用的颜色、字号、间距等参数；修改品牌时应先更新这份源文件，再同步展示页和演示。`品牌资料/brand/component-inventory.json` 记录 31 个组件家族及其状态规范；组件家族指同类控件的变体集合，例如按钮包含主要、次要和禁用等样式。清单不代表生产组件均已开发完成。

PPTX 编辑所需的 Manrope 与 Noto Sans SC 字体在 `品牌资料/brand/showcase/fonts/`。先安装字体再重新打开演示，可减少替换字体引起的换行变化；阅读定稿版面优先使用 PDF。两份字体许可证随文件提供，转交字体时请一并保留。

`品牌资料/概念图/` 保存本次 AI 生成的原始 PNG，人物与场景为虚构概念，不是真实客户或团队照片。Logo PNG 是方向概念，尚不是可直接交付印刷的最终矢量标志。仅供审阅的透明 Logo 尝试不放入主素材包。

[Figma 文件](https://www.figma.com/design/qw2UHml58nEnQLtUbC058Z)目前仅部分变量已导入；受调用配额限制，完整原生组件、变体及产品页面尚未完成。继续设计请以本地规范为依据，不把该文件视为完整组件库。

## 调整财务模型

研究模型已确认包含联合执行压力测试，24个月融资规划为 RM2,160,000。数字为规划情景，阅读时请同时查看假设与组合压力条件。

普通阅读先看`研究资料/research/operating-model.md`，无需运行程序。JSON 文件是可编辑数据，不是 Excel 工作簿。

需要重算时，请让熟悉模型的同事复制研究文件夹，修改 `model-inputs.json`，再在同一目录运行 `python3 model-source.py`。它会重新生成 `model-calculations.json` 和经营模型说明；不要使用 `--init` 覆盖已有假设。重算后还要检查解释性案例和来源价格，并同步演示中的数字。

## 查找证据

`研究资料/来源链接.md` 汇集外部证据；市场资料与模型也各自保留来源、日期和口径。链接指向原发布方或界面来源，部分页面可能需要账户。资料包保留研究笔记与来源指针，不另附大量网页或报告快照，也不提供 Whop 截图作为可任意复用的素材库。
