# Wringy 融资节奏与退出路径｜PPT研究输入

核验日期：2026-09-12。范围：资本节奏、融资准备与退出；不是市场规模或最终融资预算。事实来源见同目录上一级 `capital-sources.json`（8项一手来源）。本文所有 Wringy 目标、阶段门槛与时间安排均为**建议草案，未获创办人批准，未被外部客户验证**。

## 结论与使用边界

**建议先规划一轮天使／种子前融资，用钱证明马来西亚品牌愿意持续为 Creator Rewards 付费，再决定 seed；不预设多轮天使或固定年份退出。** 天使描述投资人类型，pre-seed描述公司阶段，两者可属于同一轮。

最大风险：把投资人认可构想写成商业验证，再用尚未验证的15%收费和案例交易价推导估值。用户明确：Wringy Malaysia first、东南亚为长期方向、Creator Rewards先行；15%品牌奖励外加费只是演示；尚无外部客户／供应商准入。Belcort是创办人关联开发公司，不设自聘开发团队。这些是2026-09-12当前任务指令给出的项目事实，不冒充第三方研究。

直接资料检查：当前 `sources/` 为空；未见可供此worker核验的已批准商业里程碑或Belcort报价。缺口只需主任务补入并确认里程碑、报价和现金表，不阻碍本研究落盘；确认预计需一次创办人审阅，供应商报价时间未知。本worker不委派，不修改任何只读资料。

## 可上主PPT：先融一轮，用证据决定下一轮

> 本轮先把马来西亚 Creator Rewards 跑通：品牌真实付款、创作者按规则完成任务并拿到奖励、品牌愿意再次购买。建议一轮天使／种子前融资，可分批交割；seed和A轮由业务证据触发，不按日历自动发生。

| 安排 | 对Wringy的建议 | 如何避免把名字当进展 |
|---|---|---|
| 一轮天使／种子前融资 | 用同一验证目标募集启动资本；融资额与核定现金预算一致 | 多位天使参与不等于多轮融资 |
| 分批交割（closing） | 同一轮框架内，投资人可先后签约和付款；以实际法律文件为准 | 收到第一笔钱、第二笔钱不自动命名angel I／II |
| 追加融资（extension） | 仅在已有验证进展、剩余缺口明确、额外现金能完成具体目标时评估 | 不是必经第二轮；也不保证现有股东追加 |
| 种子轮（seed） | 验证马来西亚商业重复性后，融资扩大可复用的销售与交付 | 不是仅凭上线或创作者注册数启动 |
| A轮（Series A） | 收入留存、获客效率和服务能力可随规模改善后，再评估扩大市场 | 东南亚愿景不等于已具备跨国扩张条件 |

## 可上主PPT：下一轮需要什么证据

以下是建议的检查项目，具体数值应与整体预算和增长计划一同审批；不要填入未经验证的“行业标准门槛”。

| 到达哪个阶段 | 必须拿出的业务证据 | 资金支持什么 |
|---|---|---|
| 本轮启动后，先完成首次真实交付 | 外部品牌完成准入并付款；创作者有资格参与、完成任务、通过审核并获得奖励；完整记录争议与退款 | Belcort按验收交付、必要工具服务、客户开发与创作者运营 |
| 为seed做准备 | 多个非关联品牌真实付费；按首单月份追踪复购；实际收取的平台费、奖励支出和人工交付成本可对账；不是靠持续补贴才有订单 | 复制已验证的马来西亚销售方式与交付流程，提高留存及效率 |
| 为A轮做准备 | 连续多个客户批次的收入留存、获客成本回收与毛利有可核查趋势；收入增长没有等比例增加人工；扩展第二市场前已验证当地需求与交付可行性 | 放大有效渠道，选择性扩展东南亚市场；不一次铺开SEA |

“贡献毛利”在本方案指平台净收入扣除每单直接服务成本后的余额；奖励代收代付是否纳入收入需会计确认。**奖励资金、交易流水、平台收入、融资款分开列示**，避免用大额奖励流水掩盖平台尚未验证的收入。

## 融资金额与用途的衔接规则

本worker没有Belcort正式报价、真实获客成本、在手现金和其他已批准成本，不给伪精确RM金额。主任务应把预算表的最终金额接到本节，不从美国融资中位数或收购价格倒推。

建议计算：**融资需求 = 达到下一里程碑前的累计经营现金缺口 + 一次性支出 + 筹资延误缓冲 − 可用于经营的现有现金**。逐月现金表已列入的一次性支出不可再加一次；品牌预存奖励与受限制资金不能当作自由经营现金；未签约收入不能作为确定到账扣减。至少保留基准及延迟到账两种情景。**未来seed／A轮如用“预计月支出×资金覆盖月数＋缓冲”等方式推算金额，必须标明为Wringy内部预算情景、列出假设并待届时重估；不得包装为马来西亚或行业平均融资金额。**

资金用途可以归入四类，但金额与比例由预算负责者核定：

1. **可交付产品：** Belcort分阶段开发与维护、外部服务费；不列Wringy自聘工程师。关联关系、报价、交付验收、源代码／知识产权归属和移交安排需在融资材料中透明披露；这些目前是待核验安排，不写成已有合同保障。
2. **真实付费验证：** 马来西亚品牌销售、客户成功、创作者运营与必要的有上限试点预算；不能把常态品牌奖励全算成Wringy长期补贴。
3. **可靠运营：** 核验、客服、反作弊、支付与对账、必要法律／财务支持。
4. **经营及融资缓冲：** 覆盖验证或交割推迟，按月跟踪可用现金；不把下一轮必定到款当作生存条件。

建议从本轮结束就整理投资人关系及月度证据；**剩余可用现金约9个月时更新融资准备，约6个月时根据证据决定正式募资、缩减开支或验证范围**。这是Wringy建议的管理触发点，不是市场平均募集耗时。进度偏离时及时调整，不等现金快耗尽才找extension。

## 可上主PPT：退出选择与当前任务

**把可持续业务建成有价值的资产，再争取流动性。战略并购作为优先研究方向；二级老股转让作为阶段性选择；IPO仅保留为远期选项。** 以下是路径解释与建议，不是任何退出承诺。

| 路径 | 谁拿到钱、意味着什么 | 对Wringy的实际含义 |
|---|---|---|
| 战略并购 | 买方购买公司股权或业务；股东能取得多少回款取决于交易结构、债务与股东权利 | 长期打造可整合的品牌关系、创作者网络、效果数据与交付流程；先证明独立经营价值 |
| 二级老股转让 | 新买方购买现有股东股份，卖方获得回款；不等于公司获得新资金 | 未来融资／交易时可讨论部分流动性；有无买方、转让限制和同意条件需逐案确定 |
| 远期IPO | 首次公开发行并上市；上市本身不代表所有老股已出售 | 需规模、治理及市场条件；不在当前阶段承诺上市年份或上市地点 |
| 分红 | 公司分配现金收益，股东仍持股 | 是投资回报方式，**不是退出**；不与上述路径混列为第四种exit |

### 投资人必须理解：公司回本，不等于股东拿回投资

- **公司经营回本≠投资人退出。** 公司收入足以覆盖经营开支，或已赚回早期经营投入，描述的是公司经营情况；若投资人没有出售股份、获得分配或参与其他回款安排，资金不会自动回到投资人账户。例如Wringy当月平台收入足够支付运营费用，天使投资人的股份仍在公司里。
- **新一轮增资通常把钱投进公司，不自动购买老股。** 例如seed投资人认购Wringy新发行股份，资金用于公司增长，早期天使不会因此自动收到回款。若同轮另有老股转让，必须单独约定购买对象、金额和条件，并将公司募资额与老股交易额分开披露。
- **稀释与清算优先权会影响最终净回款。** 股权稀释是公司发行新股后，未同比跟投股东的持股比例可能下降；清算优先权是符合约定的出售、清算等事件发生时，某些股东享有优先分配权。因此不能直接用“公司卖价×最初持股比例”计算天使回报，应按退出时实际股权及条款分配，并考虑债务、交易费用和税费。上述是机制解释，Wringy具体权利安排尚待条款与本地律师确认。

不承诺回报倍数、不设固定退出年限；不要在图里画出确定的“第5年卖给某集团”。
