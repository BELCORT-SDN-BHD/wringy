## 已确认与尚待确认

创办人已确认Content Rewards先行、Prototype＋可使用Beta研发上限RM50,000、第一轮研发与地推、第二轮营销，未来逐步加模块。长期马来西亚先发及东南亚方向保留，开发由关联公司Belcort负责，不自聘开发团队。

研发上限属于创办人预算约束，不是已完成产品或供应商保证报价。模型暂把RM45,000留给交付，RM5,000留在研发上限内作预留，分配仍待正式报价。安全、权限及真实数据的基本要求不能因封顶而省略；超额先缩减非必要范围。

六个月、非研发费用、单场成本、15%费率、RM5/千次奖励与客户目标均为内部讨论假设。首轮资金两种场景：不含创办人津贴RM70,000；含每月RM6,000津贴RM110,000。尚未决定最终募资额、估值或持股。零津贴假设创办人自行承担生活费用，尚未确认，不等于创办人劳动没有成本。

基础支出RM63,620，包括研发上限50,000和非研发13,620；只对非研发加15%缓冲RM2,043，再加取整储备RM4,337，合计70,000。研发内部预留不重复加缓冲。无收入抵扣，客户奖励不充作公司经营现金。试点费用池的16场用量只是成本控制算例，不是签单预测。

单场演示：RM2,000奖励已赚取，外加15%费产生RM300服务收入；3小时劳动按RM30计RM90，数据20、收款10，经济贡献180，贡献率60%。工时6小时则贡献90。本算例未计异常损失，发生时进一步扣减。该余额未扣获客、固定费用与研发，不是毛利率或净利润。现金预算中相关费用从试点资金池消耗，不能再次扣一套相同费用。

## 叙事与研究边界

先解释品牌与创作者需求、活动和资金闭环、奖励示例及收费成本，再讲Whop相关Content Rewards机制、马来西亚市场、替代方案、Beta、地推和融资。未来品牌工具、店铺、会员、课程及联盟按客户需求逐步评估，不纳入首轮收入或开发承诺。

Whop自有Program、Whop内嵌第三方教程和Content Rewards独立网页服务是不同证据对象。当前CR公开规则不自动成为Wringy规则。没有CR专属MY/SEA总预算统计，RM22.5m仅是马来西亚电商品牌子集的平台费假设容量，不是已验证需求或全平台TAM。

第二轮资金未承诺，营销需有付费、供给、复购和可靠交付证据。退出以相邻行业战略逻辑解释，不承诺时间、买方或收益。已认可产品构想不代表投资承诺。
