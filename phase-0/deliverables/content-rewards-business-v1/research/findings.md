# Wringy Content Rewards 商业模式：一手研究输入

核查日：2026-09-12，Asia/Kuala_Lumpur。研究范围只含 Content Rewards 切口，不含全 Whop 市场。未登录、创建活动、付款、联系第三方或实测到账；公开规则是产品方声明，不等于操作验收。仅写本 research 目录；未改 deck/model。

## 本次创办人确认及旧资料适用边界

当前对话已确认：**Content Rewards 先行；Prototype＋可用 beta 的研发总上限 RM50,000；第一轮重点地推销售，第二轮重点营销，其他模块后置。** 这是当前方向与预算约束，不证明具体功能已能在该预算内交付；也未确认下一轮金额、时间或必定募得。

已读旧 `phase-0/research/whop-wringy-blueprint-v1/report.md` 及 product/controls/malaysia 来源记录，并复用 `funding-growth-v1/inputs/market.md`。旧稿里的完整基础设施范围、较大研发预算、轮次和收入情景不能自动带入本轮。旧稿曾指出 V2 公告与当前创作者费率冲突；**本次直接读取的 V2 正文已写固定10%及大额按帖/周期免收费，与当前条款一致**，搜索摘要仍可返回旧阶梯和旧处理费算例。不能继续把旧摘要当现价。[CR05/CR04/CR06]

## 1. 可用于商业模式主线的判断

**品牌出奖励预算，创作者制作并在自己的社交账号发布，平台组织任务、审核证据、核对奖励与付款。** 这是 Whop 官方教程描述的内容营销机制。[CR02] Wringy 可借鉴这一业务循环，但本地品牌愿付价格、创作者供给、计量能力与持续复购尚未证实。

“Content Rewards”要分三个对象：Whop 自有 Program 条款；Whop 内嵌第三方应用教程；Content Rewards Inc 当前网页应用。CR 当前条款明确 Whop 是独立的支付与资金流服务方，CR 管活动、稿件、核验及收益逻辑；旧 Whop-hosted 活动保留参与时接受的旧合同。[CR01/CR03/CR04] **不可将现行 CR 功能统一称作 Whop 自研基础设施，也不能因域名含 apps.whop.com 就套旧合同。**

## 2. 谁付钱、费率及准确费基

| 对象 | 一手证据可以确认 | 必须保留的边界 |
|---|---|---|
| Whop 自有 Content Rewards Program | Seller 预备足够余额覆盖奖励上限及费用；Whop 向 Seller 收取 **Seller 实际付给 Participants 金额的10%**，从卖家账号扣除。[CR01] | 这是该份 Program 合同的明确费基，不推定为独立 CR 网页活动账单。 |
| 当前 CR 品牌平台费 | 标准10%、认证8%；活动先注资；V2 公告说平台费从已注资预算中扣，按批准和验证的交付使用。[CR03/CR05] | **未找到足以完整重建“含费预算÷…＝创作者毛奖”的公开等式**。不能把“预算内扣”直接改成“奖励外加10%”。正式账单需要询价/付款确认。 |
| 当前 CR 支付处理费 | 组织条款列约注资金额2.7%＋小额固定交易费，注资时单列，属于 Whop 处理费而非 CR 收入。[CR03 §4.2] | 不是全球所有币种、支付路线的最终报价；固定金额本次不作已知值。 |
| 当前 CR 创作者费 | CPM 每次奖励固定10%；按帖/周期活动预算不足 US$5,000 时10%，达到 US$5,000 时0%。免费转至 Whop 余额，不等于银行提款与换汇全部免费。[CR04 §5；CR06] | 不沿用旧7%或25%阶梯，不把品牌10%＋创作者10%说成总预算20%的收入。 |
| Wringy 拟议模式 | 原项目演示：品牌在已确认奖励外加15%，不再扣创作者平台费。 | **仍是待客户验证假设**，本次创办人确认研发上限没有同时批准15%定价。不能称照搬 Whop 精确收费。 |

说明性算术（非市场价格）：若适用 Whop 自有 Program 费基，实际奖励 US$100 对应 Program fee US$10，二者共 US$110，未包含其他适用费用。若 Wringy 沿用项目演示，奖励 RM1,000 对应 fee RM150，二者共 RM1,150，未计税/外部费。奖励本金不能用于解释平台服务收入或研发资金。

## 3. 投稿、审核与合格播放：不要把“有播放”写成“必付款”

Whop 自有 Program 依据 Offer 的费率、截止日和最高支付额支付批准稿件；排除机器人、脚本、欺诈或诱导制造的观看。达到上限或截止后新增观看不再产生该 Offer 奖励。[CR01]

当前独立 CR：创作者连接账号，发布后交公开链接；可选择先交草稿预审。**草稿批准≠公开稿最终批准**。人工决定内容批准/拒绝；风险分数可触发暂停与人工处理，不能把分数读成虚假播放百分比。当前组织合同明确没有自动批准，不复用旧教程“48小时自动批准”。CPM 合同写批准后7日计酬＋3日持有，风险标记可暂停；余额结算和银行到账是不同阶段。[CR03/CR04]

当前文件同时出现“活动有资金并开放时可继续累计”和七日窗口说明；其衔接未完全明确，**不要为 Wringy 直接抄一份无限累计合同**。公开 API 读取数也不自动等于独立真人、马来西亚受众或增量销售。

## 4. Discover 是找任务，不是保证分发

CR 的 Discover 定义是公开活动列表；创作者找活动后自行制作、发布。社交账号连接用于所有权与只读分析，CR 条款说不会代发。[CR04] 组织条款 §21 明确不保证活动表现、观看量或无欺诈结果。[CR03]

可用表述：**“让创作者发现品牌任务，并按明确规则参与传播。”** 不可用表述：“付钱即获得保量曝光”“自动分发给百万创作者”“保证病毒传播”“保证真实马来西亚观众”。没有创作者接受、合格发布和实际观看，公开列表本身不产生交付。

## 5. 两个可画成流程图的事实型示例

两者均为官方机制示例，**不是虚构客户成功案例，不代表 Wringy 已上线**。

### 示例 A：把已有长内容剪成短片，再进入审核

图示：**品牌提供授权播客/直播素材 → 设置每千次奖励与上下限 → 创作者剪辑并在自己的社交账号发布 → 提交 → 达到教程所设门槛后进入审核 → 合格作品按规则确认奖励。**[CR02]

官方教程自带算例：每千次 **US$3**、最低奖励 **US$6**，达到 **2,000 次播放**才进入该教程的审核队列。它表示队列门槛，**不表示达到2,000次就无条件到账**。可用三张小卡画“素材—短片—审核”；不加品牌名、订单增长或ROI。不要把内嵌教程队列行为泛化为现行 CR 所有活动必有的规则。

### 示例 B：原创内容先预审，再公开发布与核验

图示：**品牌启用预审并给出要求 → 创作者上传未发布原稿 → 品牌批准/要求修改/拒绝 → 创作者在社交账号发布 → 提交公开链接 → 成稿合规与数据风险检查 → 奖励余额 → Whop 提款。** 原创 UGC 来自 Whop 教程，预审到付款关系来自当前 CR 条款。[CR02/CR03/CR04]

画面应分开“草稿通过”“成稿通过”“可用余额”“银行到账”。此示例不填虚构奖励金额、创作者人数或销售提升；不承诺每个结算窗口准时到账。现成品牌 logo 或平台“已付XX”宣传不足以证明一宗可审核成功案例，本次不采用。

## 6. 三类替代方案：比较购买结果，不贬低现有产品

| 替代方式及官方证据 | 它能解决什么 | Wringy 差异化只能如何假设 |
|---|---|---|
| 代理/制作伙伴：TikTok One 官方支持连接 production partners、规模化创意及广告管理器联动。[CR07] | 品牌购买内容制作与活动执行，可结合付费广告扩量。该页没有统一代理费率，不能编造“代理都昂贵/低效”。 | **假设**地推协助本地中小品牌把一次简报变成多创作者可执行任务，并用低自动化运营验证成本；代理也可能是客户或招募伙伴。 |
| Influencer 合作：TikTok One 支持直接邀请、开放申请及已有帖子授权同步到广告管理器。[CR07] | 可选择创作者并建立品牌合作，且已有传播/广告路径。 | **假设**Wringy 更聚焦奖励规则、可追溯应付及本地服务；不能说其他平台没有审核、数据或支付。CPM 不自动比达人合作便宜。 |
| Affiliate：Shopify Collabs 用推荐链接/折扣码跟踪促成购买并支付佣金。[CR08] | 按可归因销售回报创作者，更接近成交目标。 | **假设**Content Rewards 适合希望激励内容产出/合格传播、尚不能把所有价值归因到订单的品牌；播放不能冒充销售。两者可互补，但联盟模块后置。 |

Shopify 当前帮助页说明暂停新创作者自助注册，但商家仍能直接邀请并接受申请。[CR08] 不把“存在官方替代”写成“所有MY品牌今天都能无条件接入”。本次没有可比马来西亚代理价格、平台实际履约成本或获客ROI证据，故不列排名或节省百分比。

## 7. 马来西亚市场：只作背景，没有 Content Rewards 专属 TAM

复用本项目已验证的一手来源：**FY2025 MY 数字广告支出估计 RM2.9594bn**；**2025E MY 电商 GMV US$20bn**；**2022 年参与电商的经营单位78,236个**。[CR10–CR12] 广告支出、消费者成交额、经营单位数量三者不是一个费收入市场。

**本次没有可靠一手 MY/SEA Content Rewards 总预算统计，不能声明 CR 专属 TAM。** 旧 RM22.53m/RM4.51m 只是电商品牌子集的假设年费容量，非全 Wringy、非整个内容品牌市场、非已批准收入预测。如引用，必须重新展示独立活跃调整、适配率、奖励预算和收费率；不因改名 Content Rewards 就扩大数字。

不必为首版堆区域大数；若主稿复用旧区域页，US$185bn 是2025E ASEAN-10 电商GMV，25%视频电商须保留原报告 SEA-6 边界，并引用旧研究中的原报告；本次12条来源不重复扩展区域报告清单。

## 8. RM50,000 下可以提出的商业验证，而非交付保证

研究建议：把可用 beta 聚焦一条已获准数据渠道、少量邀请品牌/创作者、可核对活动规则、提交与人工审稿、奖励计算记录和经批准的付款流程。**是否能在RM50k内交付，仍需Belcort分范围报价与数据/支付准入证明**；本研究没有估工或授予实现批准。

不默认包含：跨平台自动核验、社交自动发布、百万创作者市场、自建钱包、多国结算、专有反作弊、完整代理工作空间、Whop应用市场。人工协助也要计成本，不能把创办人的审核时间当永久免费。

第一轮地推可以验证“谁会真实付费、何种素材和目标、复购及每场人工成本”；第二轮营销可在这些证据后测试规模化获客。此处不新增客户数量、日期、融资额或回报承诺，亦不改既有模型。

## 9. 必要法律与数据边界（产品约束，不是MY法律意见）

- **数据能力**：TikTok Query Videos 需授权用户及 video.list，返回所属视频、view_count等；公布字段无逐观看者身份或国家。[CR09] 因此不能仅凭总播放或账号受众占比开出“真实MY播放”的结算凭据。公开文档不证明Wringy用途与生产权限已批。
- **素材/披露**：CR合同要求品牌有素材权、创作者遵守广告及社交规则；草稿过审不免除公开稿披露义务。[CR03/CR04] Wringy 应确认音乐、人物、剪辑/转载及广告再利用权限；美国FTC文字不能直接冒充马来西亚合规结论。本次不新增未核查的本地法条，具体使用本地专业意见。
- **钱与责任**：品牌奖励预算、平台服务费、供应商处理费分开；先确定退款、在途奖励和失败付款责任。CR依赖Whop付款的事实不证明Wringy可以无准入复用该路径。[CR03]
- **隐私及风控**：只收必要证据、限制访问、明确保留与撤销；风险标记不等于作弊定罪。不得以“零作弊”或“已获数据许可”包装尚未验收的beta。
