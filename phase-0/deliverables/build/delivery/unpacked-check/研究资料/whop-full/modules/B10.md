# B10｜身份核验、风险、退款争议与税务政策

证据口径统一见[证据指南](../evidence-guide.md)；演示与真实依赖边界见[共享建设参考](../build-reference.md)；本卡保留的文/API、D/A、营销等本地图例仅作别名，以统一指南为准。API 路径中的 beta 不单独证明预发布；成熟度须依据具体页面正文及版本，未核实则保留未知。

状态：**研究型候选模块，不是已批准规格，也不是 Whop 内部架构。** 核验日期：2026-09-10。本卡为 B10 的规范功能清单；[综合报告](../payments-money-trust.md)保留证据冲突。☐ 是未来候选能力，不表示已经实现。下列文档仅核验公开正文，无账户、支付或 API 实测。

## 目的、角色与边界

为买家、商家、企业平台、风控审查员、客服案件处理者、财务和税务人员提供可追溯的准入、纠纷处理与资金风险决定。

**拥有的业务概念（分析）：** 核验档案、补件要求、资格、风险控制决定、准备金政策、退款/争议案件、证据包、裁决及申诉、税务模式与适用规则。B01 拥有登录身份、组织、团队及商品目录；核验不取代这些身份记录。B02 执行退款及收费；B09 执行余额保留与资金移动；B04 提供通用客服界面，但不另存退款裁决；B05 管理发现与评论，规则执法可调用本模块。

## 正常与失败流程

**准入：** B01 账户 → F01 核验 → F02 补件或审查 → 通过后向 B02/B09 输出具范围的资格；状态变更通知后重新读当前结果，不能把一条通知当作永远通过。

**纠纷：** 买家对 B02 某笔付款提退款 → F09 案件、证据及商家响应 → F08 裁决 → B02 执行退款、B09 记账、B03 调整相应权益。未响应七天升级平台，支持文档所述一次申诉。银行拒付走 F10 单独流程，收到拒付即暂扣原争议金额及适用费，胜诉返争议款，败诉落实损失。[平台案件](https://docs.whop.com/manage-your-business/manage-payments/resolution-center.md)、[拒付](https://docs.whop.com/manage-your-business/manage-payments/manage-disputes.md)

**失败：** 补件驳回回到 action_required；高风险可延迟提现、增加准备金或暂停融资；余额不足无法完成退款时必须显示未完成，不能仅凭裁决通知买家“已到账”。Apple 内购及 Coinbase Commerce 的案件路径不能照搬银行卡。税务覆盖之外不能显示“Whop 已代缴”。F01/F02/F06/F08/F12 及综合报告有来源。

## 收费及责任

正常核验和平台案件未取得统一独立收费证据。风控有事件/交易收费：3DS $0.03、Radar $0.07、拒付 $15、早期预警 $29；按实际事件/开关而非每单必叠加。高风险处理费可出现但未核统一金额。[定价](https://whop.com/network/pricing/)、[风险控制](https://docs.whop.com/trust-and-safety/account-health/controls.md)

卖家承担适用退款及拒付损失；持有准备金不是 Whop 收入。税务帮助页对两种托管模式写 2%，但平台报告 C08 记录 Fees 文档为 0.5%；这是待核的跨来源/抓取差异，不能作为通用报价。见[综合报告税费冲突](../payments-money-trust.md#tax-fee-conflict)及[平台报告 C08](../platform-ai-enterprise.md)。税金另算；代算模式税款交卖家，代缴模式向税务机关缴纳。实际覆盖及合同边界见[税务正文](https://docs.whop.com/payments-and-billing/fees/taxes.md)。没有证据据此推算反欺诈利润、实际坏账或税务业务利润。

## 依赖（分析；能力依赖，不是整体模块先后）

- **B01**：组织、持有人、团队权限、商品分类与政策资料；B10 只存核验与审查事实。
- **B02**：原付款、费用、账单、认证及退款执行；税务规则由 B10 定，收费计算执行由 B02 调用。
- **B03**：交付/访问证据和退款后权益动作；不由 B10 再建会员状态。
- **B04**：客服消息、统一案件入口和数据呈现；本模块拥有财务纠纷决定。
- **B09**：冻结、准备金、负余额、退款资金及账务结果。
- **B11**：第三方核验、处理商与税务接口契约和事件交付规范；接口契约不能改写裁决事实。

## 首个纵向切片及验收候选（未批准）

**切片：单笔模拟网页卡付款的退款申请 → 人工决定 → 唯一退款 → 审计记录。** 同时使用模拟核验及风险结果，不实施真实资金处理。

1. B10-A01：案件必须关联授权可见的付款；已全退付款不能重复开案，买家与商家只能访问有关案件。
2. B10-A02：批准、拒绝、补证有操作者及时间；逾期进入升级队列，不能静默消失。
3. B10-A03：同一批准重复送达只触发一次 B02 退款；B09 资金不足时显示“待执行”，非“完成”。
4. B10-A04：退款成功后可追溯原付款、决定、资金记录与 B03 权益处理。
5. B10-A05：平台退款与银行拒付状态分开，发生并行案件时避免双重赔付，保留人工处理路径。

扩展点：核验提供方、按国家/合作方规则、税务计算商、证据收集、自动裁决阈值与申诉；所有新政策应有生效时间与依据。指标候选：核验完成率、补件率/耗时、误拒率、案件首响与结案时长、按成熟购买批次争议率、追偿回收率、准备金占用天数、税额对账差异；均为未来衡量建议，无 Whop 实际值。
