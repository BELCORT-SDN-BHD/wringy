# B05 商品发现、商城搜索与评价

证据口径统一见[证据指南](../evidence-guide.md)；演示与真实依赖边界见[共享建设参考](../build-reference.md)；本卡保留的文/API、D/A、营销等本地图例仅作别名，以统一指南为准。API 路径中的 beta 不单独证明预发布；成熟度须依据具体页面正文及版本，未核实则保留未知。

状态：**研究候选模块；不是已批准规格，也不是 Whop 内部架构。** 核查日期：2026-09-10。下列是本模块唯一功能清单；证据讨论见[分发专题](../distribution-creators-growth.md)。已读公开正文，未登录、调用业务 API 或实测交易。API＝公开接口契约，不等于所有界面已上线。

## 用途、参与者与边界

帮助买家发现、比较和判断商品，帮助卖家获得自然流量；平台审核员控制上架与评价质量。拥有：商城收录、搜索条件、发现排序、评价与审核状态。B01 提供商品目录，B02 提供收费方案、价格与付款事实，B03 提供交付权益，B10 负责退款争议裁决，B09 负责相应资金记录；站内付费曝光属于 B08，招募推广者属于 B07，创作者找任务属于 B06。

## 流程和收入

正常：商品资料齐全 → 提交收录 → 审核通过 → 搜索/筛选 → 详情及评价 → 转交结账 → 买家体验后留下评价。最后一步的具体编辑界面与资格门槛未实测，不能由只读 Review API 推定。

失败：资料缺项不能提交；待审不应可搜索；下架退出结果；评价待审或移除；无结果/分页结束；不合法的排序组合失败。拒绝原因、申诉和重新提交流程未完全公开。

商城分发费：2025-05-12 公告称旧 Discover 30% 改为 0%；不等于支付、affiliate 或广告免费。[公告](https://web.whop.com/blog/whop-changelog/)；[支付定价](https://whop.com/network/pricing/)。买家仍向卖家购买商品；没有核实目前每个账户的商城账单。

## 依赖与候选切片（分析）

- B08：只接受带广告标识的付费展示与转化测量，不混入自然排序。
- B07：商品可被推广，但佣金条款和归因归 B07。
- B01：身份、组织和商品目录；B02：收费方案、价格与付款事实；B03：购买后的权益；B04：通用报表与客服界面；B09：退款资金事实（需要展示时）；B10：风险及退款争议裁决，评价审核状态仍归 B05；B11：外部接口契约。以上归属是研究分类，只依赖所需能力，不是整模块瀑布建设。B06 的任务发现是独立场景，B12 AI 工具不是本模块首片的必要依赖。

首个纵向切片：一种商品的“提交审核→公开类目搜索→查看评价→跳转购买”。假设验收：未通过审核不可搜；价格过滤采用同一商品价格源；下架即从结果移除但不改订单；未付费与未知评价不标“已购”；重复翻页无重复项。这些是未来测试候选，不是已通过测试。

建议指标：搜索到详情率、搜索无结果率、详情到付款率、收录耗时、有效评价率、评价申诉改判率。均为待测指标，没有 Whop 实际值。

未知：完整实时类目树、个性化/推荐权重、热榜计算、评价编辑期限、商家回复及申诉后台、虚假评价误报率、跨渠道归因优先级。匿名访问 /discover/ 本轮返回营销首页，未观察到完整商城界面；不能据此宣布商城被取消。
