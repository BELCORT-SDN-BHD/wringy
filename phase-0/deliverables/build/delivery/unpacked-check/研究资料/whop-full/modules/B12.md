证据口径统一见[证据指南](../evidence-guide.md)；演示与真实依赖边界见[共享建设参考](../build-reference.md)；本卡保留的文/API、D/A、营销等本地图例仅作别名，以统一指南为准。API 路径中的 beta 不单独证明预发布；成熟度须依据具体页面正文及版本，未核实则保留未知。

## 目的、参与者与边界

帮助创业者从想法进入可售业务，也帮助已有商家迁入、自动经营、学习及扩大同行网络。参与者：初创商家、已有经营者、蓝图发布者、AI 工具用户、外部编程助手、公司注册申请人／共同创始人／服务提供方、导师、学校／学生、WhopX 成员与运营团队。

**本模块拥有的业务概念（分析建议）**：创业会话、AI 操作预览与确认、业务上下文、蓝图与来源归因、网站项目和发布意图、迁移批次与记录映射、公司注册申请、培训项目与参与、收入门槛权益。**范围内**：把既有平台能力组织成创业／迁入／成长流程。**范围外**：底层商品定价引擎、真实账本、支付审核、法律实体登记机关、第三方模型训练及应用内部架构。AI 调用付款能力不意味着 B12 拥有付款业务规则。

## 正常与失败流程

**创业正常链**：描述业务／选择蓝图 → 选择或建立商家业务 → 审核商品、价格、站点配置 → 发布独立网站 → checkout 收款 → 使用数据和人工反馈继续修改。前半链来自 F01/F07/F08；“审核后再发布”是未来产品建议，不是声称所有 Whop AI 操作都有该关卡。

**经营自动化链**：授权外部 AI → 指定业务 → 读取状态／准备操作 → 用户同意 → 相同参数与确认令牌执行 → 查询真实结果。F05 文档明确要求重要操作分两次执行；不能把权限广度误写成“只读”。

**迁入正常链**：连接 Stripe → 预览订阅 → 完成支付方式转移准备 → 排除不迁项目 → 确认 → 迁移报告 → 下一个续费周期验证。F10 的“单击”营销不包含全部前置人工步骤。

**已证实限制与失败**：MCP 授权过期／无效、确认参数变化失败；站点自动注入权限不能发起转账／提现；媒体生成要等待就绪。Stripe 迁移仅卡支付、active／trialing 状态、客户有邮箱、金额不少于 US$1；转移后更改支付方式不包含在旧快照中。失败项目可通过报告识别；重跑跳过已成功项目。[MCP](https://docs.whop.com/developer/guides/ai_and_mcp.md)、[Hosting](https://docs.whop.com/developer/websites/hosting.md)、[媒体](https://docs.whop.com/api-reference/beta/media/generate-media-asset.md)、[迁移限制](https://whop.com/blog/migrations/)（2026-09-10）

**建议链限制**：B12-F14 的 executed／redirected 记录只说明客户端步骤被记录，不能代替 B01 商品、B02 交易或 B03 交付的真实成功状态；它不是 F05 MCP 已确认业务操作的替代物。

**未来待设计的失败链**：AI 误定价／误选业务的恢复、蓝图部分创建失败补偿、生成失败退款、网站所有权争议、注册被拒／撤单、WhopX 收入回落／异常交易资格申诉、教育内容过期和项目结束退出。公开资料不足以确认 Whop 已怎样处理。

## 依赖关系与正式所有权

以下为所需能力，不要求先完成整个依赖模块，也不声称 Whop 实际这样拆代码。B12 拥有 AI 业务工具和经营项目编排。

| 依赖 | 所需能力与不重复拥有的事实 |
|---|---|
| B01 | 用户、组织、团队、商品；蓝图创建商品时写回正式目录。 |
| B02 | 价格计划、付款、发票执行；AI 不能另存一份收费计划。 |
| B03 | 网站购买后的会员权益和交付；University／WhopX 的访问执行也复用它。 |
| B04 | AI 经营查询所用数据、分析、通用支持及教学辅导问题记录。 |
| B05 | 蓝图发现、排序及评论通用能力；B12 仅拥有蓝图内容和部署关系。 |
| B07 | 蓝图推荐来源和佣金义务；B12 提供“部署副本来自哪个蓝图”事件，不自行维护佣金账本。 |
| B08 | 网站像素、广告及转化归因；B12 建站时配置接入，不另算广告收益。 |
| B09 | 媒体费用扣款、注册付款对应资金记录和 WhopX 收入资格读取。 |
| B10 | 迁移后的风险／退款／税规则、公司验证；美国实体服务不意味着本模块能决定当地政策。 |
| B11 | 开发者契约、OAuth、凭证、API／SDK、应用发行和外部连接。 |

## 首条纵向切片与验收建议

**建议首片：一个经人工校验的本地业务蓝图，生成一个可预览、可测试结账的网站。** 例如马来西亚导师把一个明确价格的课程卖给测试买家。不要在同一首片承诺自动注册公司和全能 AI 经营。

- B12-AC01（F01/F08）：蓝图清楚显示将创建的商品、价格、网站和来源；确认前不创建正式售卖对象；蓝图作者不能读取副本商家客户数据。
- B12-AC02（F07/F08）：两家测试商家得到隔离副本；其中一家改价不影响另一家；支付入口读正式商品价格，不能和页面文案分叉。
- B12-AC03（F07）：发布失败显示可操作原因，保留上次可用版本；恢复旧版不重复创建商品或删除有效订单。
- B12-AC04（F05）：若加 AI 编辑，先展示业务和影响；改参数使旧确认失效，重复执行不重复创建／收费。
- B12-AC05（F08；跨模块验收候选，blocked-by: B07-F14）：由 B12 提供蓝图部署副本与发布者来源，用模拟销售核对 B07-F14 的归因及佣金义务；不自动纳入首条切片，需在后续范围选择时单独决定。未来平台奖励基数待确定，不把 Whop 的 10% 利润分成条款自动作为 Malaysia 平台承诺。

后续切片：只读 AI 经营问答 → 一种可确认修改 → 迁移预检和人工协助 → 完整迁移 → 教学项目 → 收入资格社群。公司成立服务需单独业务／合作方方案，不作为普通表单功能附送。

## 建议衡量与未知

建议衡量：想法到可预览站点时间、蓝图部署成功率、发布后首次成交率、AI 操作纠正率、确认取消率、迁移合格率与首次续费成功率、教学参与到真实开店转化、WhopX 合格成员参与／留存。均为未来拟测，没有声称任何 Whop 实际数值。

未知：Whop AI 具体模型／训练／成本；建议链未来是否具有服务端执行（当前 Execute 明确没有）；跨账户操作隔离实测；网站托管额度；蓝图版权许可及奖励结算；迁移全量支持矩阵；LLC 被拒后的责任与退款；University 当前服务承诺；WhopX 收入计算周期、退款扣减及降级；马来西亚经营者适用条件。所有当前 UI 仅由公开文字或官方图文核实，未登录体验。
