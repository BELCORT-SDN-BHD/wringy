# 研究资料阅读说明

先读 research/sea-market.md 与 research/operating-model.md，再查看来源链接.md。

model-inputs.json 是可编辑假设；model-calculations.json 是计算结果；model-source.py 是仅依赖 Python 标准库的重算方法。保留这三份文件和说明在同一 research 文件夹。复制后修改输入，再于该目录运行 python3 model-source.py；不要使用 --init。重算会覆盖结果和经营说明，解释性案例与来源价格仍须复核。

已纳入联合执行压力测试：combined_execution_stress 的24个月融资规划为 RM2,160,000；这是情景计算，不是已发生业绩或保证融资额。首发采用品牌直接付创作者，Wringy仅收自身服务费；未来集成代收另列压力测试。不同年度预算、采用速度与成本情景不可拼接。
