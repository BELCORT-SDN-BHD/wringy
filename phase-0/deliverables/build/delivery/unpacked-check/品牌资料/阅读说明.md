# 品牌资料阅读说明

打开 brand/showcase/index.html 浏览31个本地HTML/CSS组件家族；保留其脚本、样式、字体和图片目录。原生控件演示只改变本地状态，不执行账户、发布、上传或付款业务。implementation-coverage.json说明已呈现的范围，不代表全部变体组合都已实现。

brand/tokens.json为唯一设计数值源；showcase内的token文件是派生投影，不要各自修改。brand-strategy.md、design-system-spec.md和component-inventory.json提供策略与规格。

首发创作者示例为已批准、待品牌直接付款、到账未确认；UI-PAYOUT-CONFIRM是未来集成路线，非首发钱包。screens内5张图片均为示例界面。

brand/showcase/fonts包含Manrope、Noto Sans SC及官方OFL许可证，亦为三份演示使用的字体。安装字体后编辑PPTX；许可证须随字体保留。

概念图内PNG为AI生成原始概念，人物与场景为虚构；Logo是位图方向，非最终矢量商标。未收录仅供审阅的透明Logo尝试。

Figma仅部分变量导入，受调用配额限制，完整原生组件和页面未完成。可使用的本地参考不等于Figma完整库，也不代表生产应用。
