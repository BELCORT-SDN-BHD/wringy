# Wringy 毛利与回本模型

2026-09-10 · 创始人授权的财务情景草稿。金额为马币（RM），月份是项目开始后的相对月份。模型供创始人理解单位经济、经营规模和现金需求；不是客户预测、完整报价或税后财务报表。

**基准情景在第25个月首次累计回本；保守情景36个月内未回本；扩张情景第18个月回本。** 前4个月建设，后32个月经营。这里的回本是累计公司融资前现金流首次达到零，包含开发、建设运营、上线启动、持续运营和独立品牌获客费；不把融资当收入，也不把某个月经营不亏当作全部投资收回。税及部分营运资金尚未报价，因此不能当作最终投资回报承诺。

## 毛利率究竟是多少

单场已确认奖励RM10,000，另加15%服务费：平台收入RM1,500、品牌支出RM11,500。RM5／千次意味着每场需要200万次合格播放。这不是独立观众数、订单或销量。

| 20场／月示例 | 金额或比例 |
|---|---:|
| 平台服务收入 | RM30,000 |
| 可变履约600×20＋固定履约2,000 | RM14,000 |
| 毛利 | RM16,000 |
| 毛利率（以平台服务收入为分母） | 53.33% |
| 全部每场可变成本：(600＋150)×20 | RM15,000 |
| 贡献及贡献率 | RM15,000／50.00% |
| 固定履约2,000＋非履约运营15,000 | RM17,000 |
| 经营结果：尚未扣新增品牌CAC | 亏损RM2,000 |
| 经营利润率：尚未扣新增品牌CAC | −6.67% |
| 盈亏平衡：尚未扣新增品牌CAC | 向上取整(17,000÷750)＝23场 |

服务费15%、服务收入占品牌支出的13.04%、毛利率53.33%是三个不同分母。固定履约计入销售成本，所以毛利率随活动量改变。按贡献减全部固定费用，或按毛利再减非履约支出与活动佣金，结果相同；固定履约RM2,000只能扣一次。

经营结果采用折旧摊销前的现金费用规划口径，开发另列现金支出；资本化、折旧、税、利息尚未确定，**税后净利润未知**。模型的净服务费收入呈列依赖暂按代理安排的规划假设；实际主要责任人／代理人及总额／净额收入确认需按合同判断，不代表已有托管或支付许可。[IFRS解释委员会的原则与代理判断说明](https://www.ifrs.org/news-and-events/updates/ifric/2022/ifric-update-april-2022/)要求评估转移前的控制及相关事实。贡献指收入减全部随业务量变化的成本；参见[OpenStax贡献分析](https://openstax.org/books/principles-managerial-accounting/pages/3-1-explain-contribution-margin-and-calculate-contribution-margin-per-unit-contribution-margin-ratio-and-total-contribution-margin)。

## 审核与支付成本不是固定真相

RM600／场拆分为：平台审核支持300、数据100、支付150、异常损失50，全部为估计，非报价。审核300由**所有审核提交200份×含异常与申诉的平均1.5分钟÷60×RM60时薪**得到。拒绝的提交同样消耗成本；不只按获得奖励的内容计费。品牌自己的审核时间不计平台工资；申诉已经含于加权平均时间，不能再重复加一次。200份、1.5分钟和时薪都是待验证输入，不是生产率基准。新增播放、拒绝率或争议使提交量和平均时间提高时，应直接调整这些输入。

默认支付150是占位。支付费可能以品牌全部资金RM11,500计费，而不是仅对服务费RM1,500计费。工作簿“假设”的支付费模式0保留占位，模式1按全部品牌资金×费率＋每场固定费；3%纯属敏感性假设，并非Whop报价。

| 全额资金3%支付费假设 | 结果 |
|---|---:|
| 每场支付费，不含待报价出款固定费 | RM345 |
| 每场全部可变履约 | RM795 |
| 每场贡献，含150活动佣金 | RM555 |
| 20场毛利／毛利率 | RM12,100／40.33% |
| 20场经营结果，新增品牌CAC前 | −RM5,900 |
| 盈亏平衡，新增品牌CAC前 | 31场 |
| 公司回本：保守／基准／扩张 | 未在36个月内／M31／M21 |

## 品牌CAC与公司回本分开

每场RM150是活动获取／转介佣金，随所有活动支付。独立品牌获客费CAC是取得一个新增品牌的额外销售支出，设RM1,500；不含该佣金和已经计入固定运营的销售工资。第五个月首批品牌获取归入RM50,000启动池，不另加CAC。第六个月起，品牌增长和流失替补产生的新增品牌×RM1,500进入主现金流。实际账目必须继续按此分类去重，不能再把同一发票同时塞入启动、固定运营和CAC。

活动量是可编辑说明输入，每品牌每月2场；月流失率5%，用连续近似品牌数表示期望规模。留存品牌＝本月活跃品牌与上月活跃品牌×95%两者较小值；新增品牌＝本月活跃品牌−留存品牌。当月新品牌假设完成完整两场，流失从下月开始。若实际有销售前置时间、首月不足两场或流失更快，应下调路径，不能用这组假设声称已经验证留存。

**“单品牌持续每月2场、不流失的简单回收期”＝1,500÷(2×750)＝1个月。** 佣金已在750贡献中扣除。这个算式不分摊固定支出、开发或启动费，不是观察到的客户群回收期。单独的品牌获客表展示36个月留存期望贡献，公司表则纳入每月新增与替补CAC。

|---|---:|---:|---:|---:|---:|---:|---:|
| 保守 | 4 | 30／15 | 6,000万 | M18 | 36个月内未回本 | RM383,200 | −RM325,725 |
| 基准 | 8 | 100／50 | 2亿 | M10 | M25 | RM326,850 | RM596,400 |
| 扩张 | 12 | 240／120 | 4.8亿 | M8 | M18 | RM306,950 | RM2,256,675 |

完整逐月活动数在假设表和assumptions.json，非销量预测。扩张收入尤其依赖预算、复购、创作者交付和计量容量。固定费用保持RM17,000不随规模增加只为说明情景；不能声称这点人力和云预算能支持240场。需要重新验证审核吞吐、招聘与供应商报价。

回本为月末离散判断，无假装精确的日数，也不外推36个月以后的回本。M25包含4个月建设，即第21个运营月；M18即第14个运营月。

## 建设、预算与收款

历史开发锚点RM189,750分前4个月等额支付，每月RM47,437.50；同期运营RM12,000／月。M5启动RM50,000；此后固定履约2,000＋非履约15,000，共RM17,000／月。新计量、多平台数据和反作弊开发追加输入为0，**表示未报价，不表示免费或已经包含**。建设期及付款方式只是模型假设，非已签Belcort合同。

旧RM576,150是18个月零收入预算：开发189,750＋运营216,000＋上线维护云70,000＋启动50,000＋非开发缓冲50,400。非开发实际费用池为336,000；不含缓冲的支出为525,750。缓冲不是费用，不额外作为现金流支出。当前模型逐月记实际费用假设，没有把576,150整笔当作前置投资再重复扣月费。开发锚点自身已含预备金，不再重复加开发缓冲。

默认平台服务费同月赚取并收款；“服务费收款延迟”可改为1个月，成本仍当月支付。应收款与现金收入分开，36个月末未收收入不假装变成现金。仅延迟一个月时，保守／基准／扩张的回本为未在36个月内／M28／M21，峰值缺口为RM421,900／RM372,000／RM361,350。其余营运资金、退款账期、税和利息未建立，不能把未知当已核实为零；创作者代转资金未用于公司周转。

创始人投入未知，期初公司现金默认0，可编辑且只改变现金余额，不改变公司经营回本。峰值缺口为融资前累计现金流的最大负值，不含额外安全缓冲，不等同正式融资额。

## 可编辑范围与验证

蓝字浅黄是输入，黑字是同表公式，绿字是跨表公式；总览结果用深色。三情景同时保留独立明细是本轮明确要求。所有数字、公式与原生图表都可在Excel编辑。assumptions.json为本版输入与口径记录，results.json为本版基准和敏感性结果快照；以后改Excel后，JSON及报告不会自动同步，发布新版必须一起更新。

本版使用受支持的电子表格库生成并重算，检查所有公式错误、逐月核心结果与独立数学计算、费率和追加开发变化、支付全资金计费及收款延迟。另以捆绑LibreOffice进行重算并检查保存的公式缓存；实际检查记录见verification.json及cached-verification.json。未操作用户桌面Excel，不声称已通过Excel界面测试。
