# B08 广告投放、受众与营销归因

证据口径统一见[证据指南](../evidence-guide.md)；演示与真实依赖边界见[共享建设参考](../build-reference.md)；本卡保留的文/API、D/A、营销等本地图例仅作别名，以统一指南为准。API 路径中的 beta 不单独证明预发布；成熟度须依据具体页面正文及版本，未核实则保留未知。

状态：**研究候选；非已批准规格、非 Whop 内部架构。** 核查日期 2026-09-10；官方正文与 API 契约已读，未连接广告账号、安装像素或投放。`/api-reference/beta` 是当前按日期版本化的 Whop API 路径，路径名不表示预发布。按 [API Stability](https://docs.whop.com/api-reference/stability.md)，广告活动、分组、广告、受众、People、Events、Media 和 Social Accounts 属于 Current API。Elements Beta/Upcoming 的组件成熟度须依据各自页面的 SDK 版本与明确预发布说明判断；本卡所引 Elements Beta 页面明确标记 `1.0.0-beta.3` 为预发布。API 状态、SDK 成熟度、商家界面可用性与本轮未实测是四项不同信息。

## 用途、参与者与所有权

商家/品牌及其广告投手购买媒体分发，追踪何种触点与付款相连。平台负责广告账户及接入；外部网络负责投放。拥有广告活动、分组、创意绑定、受众规则、营销事件归因；B02 提供付款事实，B09 提供账本与扣款，B10 提供风险政策，B12 提供 AI 生成。B06 内容奖励按作品/观看付给创作者，与这里支付媒体费用不同。

## 正常与失败流程

连接社交身份及付款方法→安装/验证外站 Pixel→选择目标→分组受众/预算/排期→自有或生成创意→草稿→审查/发布→投放与事件→归因报表→暂停、复制或结束。生成媒体与广告消耗是两项账。

失败：缺 Page、像素或基础素材不能启动；媒体余额不足返回充值入口；媒体生成失败退款；审核拒绝读 issues；广告付款失败停止交付，修复付款后重试；受众 partial/failed 不能等同 ready，ready 也不保证 Meta 已填满人群。[API Overview](https://docs.whop.com/api-reference/beta/ads/overview.md)、[Audience](https://docs.whop.com/api-reference/beta/audiences/audience.md)

## 计价、归因和集成边界

当前业务文档称自助后台无平台/设置/月费/最低支出，只付广告费，普通信用卡、Whop Card、待结算余额可支持；但 Ads Terms 仍保留站外实际成本加 Whop 广告费、站内 CPC。**未核得统一当前加价率，不据此推算收入或毛利。** API 的 spend 为向用户收取额、发生投放后收费；AI 创意从余额独立收费。[业务费率](https://docs.whop.com/manage-your-business/growth-marketing/ads.md)、[条款](https://whop.com/whop-ads-terms/)、[开发说明](https://docs.whop.com/developer/ads/overview.md)

Pixel 的外部 purchase 会向网络传递，但 Whop purchase/ROAS 只计 Whop 处理的付款；不是商家所有收入。报表首次/末次触点模型还有“旅程含 Whop 触点即归入 Whop 桶”的规则；这不是中立多触点增量实验。[Pixel](https://docs.whop.com/developer/ads/pixel.md)、[Reporting](https://docs.whop.com/elements/beta/ads/reporting.md)

分析接入名单：Google Analytics、Hyros、Meta、TikTok、X、Reddit、Pinterest、HubSpot。归因合作名单：Triple Whale、Cometly、Trackbee、Cortana、Omni、Hyros；WeTracked 尚未来。Pixel 专门指南覆盖 ClickFunnels、GoHighLevel、Kajabi、WordPress、WooCommerce、Shopify、WebinarJam、iClosed、Calendly。[分析集成](https://docs.whop.com/manage-your-business/growth-marketing/tracking-integrations.md)、[Ads](https://docs.whop.com/manage-your-business/growth-marketing/ads.md)、[Pixel](https://docs.whop.com/developer/ads/pixel.md)。这些是已公开安装/连接能力，未逐一端到端实测。

## 能力依赖与候选切片（分析）

B01 广告主体/团队/商品，B02 付款事实，B04 通用分析展示，B05 站内付费位置，B06 内容授权凭证，B07 推广归因和额度奖励，B09 计费资金，B10 风险与退款政策，B11 外部契约，B12 生成创意。仅需对应能力，不要求先完成整个模块。

首片：单网络、单图片广告，固定日预算，支付方式检查→草稿审核→发布→一次付款事件归因→暂停。假设验收：未配置支付/身份不可发布；预算只存在一层；重复事件不增收入；支付失败停投；外部购买不误入 Whop 处理销售口径；B08 只引用付款事实。先完成测量可信度，再扩展网络/相似受众。

建议指标：投放激活率、审核通过率、付款失败停投时间、重复事件率、身份匹配率、归因覆盖率、每合格买家成本、复投率。未知：实际加价/返佣、投放账户等级的独立证明、网络返点、跨设备误归因、默认归因回看期限、隐私同意及删除端到端实现、马来西亚真实接入资格；不把“低 CPM、无限花费”营销视为结果保证。
