证据口径统一见[证据指南](../evidence-guide.md)；演示与真实依赖边界见[共享建设参考](../build-reference.md)；本卡保留的文/API、D/A、营销等本地图例仅作别名，以统一指南为准。API 路径中的 beta 不单独证明预发布；成熟度须依据具体页面正文及版本，未核实则保留未知。

## 目的、角色与边界

让商家、创作者、团队成员、企业平台及财务管理员知道钱在哪里、可怎样使用、怎样付给收款人。金融合作方执行资金服务。

**拥有的业务概念（分析）：** 资金账户、余额分类、账务活动、充值、转账、领取请求、提现目的地与报价、出款、兑换、卡与消费控制、金融产品资格引用。自托管数字资产与金融合作方持有的法币余额需分开建模。B02 拥有销售及订阅；B10 拥有身份审查、风险决定、准备金政策及税务责任。本模块执行持有/释放事实，不决定风险阈值。发卡、收益与融资是独立候选子域，不暗示一个“钱包”即可合法或技术上实现全部。

## 主流程与失败流程

正常：B10 完成收款人核验 → B02 销售结算或 F03/F09 注资 → F01/F02 显示资金 → F07/F08 按业务义务转给收款账户 → F04/F06 确认外部目的地、报价 → F05 完成出款并记账。企业平台亦可只买代付能力，不必使用 Whop 商城。

失败：转出未验证、余额不足、收款人不能收款时先解决原因再重试；出款被合规审查则不展示“即时”；审核中取消退回资金，处理中不可取消；银行退回与原成功出款不同，需保留活动链。卡消费被锁卡、额度、余额或 B10 风险规则拒绝时返回对应状态，不能当提现失败。以上流程依据 F04–F08/F11；账务一致性处理是分析要求。

## 谁付谁与收费触发

销售款及平台注资属于客户资金，不是 Whop 收入。提现按实际方式计费；充值 API 的免费不能外推银行、链上、外汇及合作方所有成本。[提现定价](https://whop.com/network/pricing/)

企业平台可以对其连接商家收 application fee；这笔平台收入不等于 Whop 收入。直收模式由连接账户负责 Whop 费用、退款和争议；平台收后再转模式由平台负责原订单的费用、退款和争议。[企业收款](https://docs.whop.com/developer/platforms/collect-payments-for-connected-accounts.md)

融资交易定价页列成功交易 15%，是支付方式收费，并不证明 Whop 收取买家全部利息或自行放贷。F12 有交换费分享公开依据，但比例未知。F14 无证据可确认管理费、利差、收益分成。未取得 Whop 自有商家贷款/营运资金垫款产品的充分一手证据，不能把消费融资、待结算提前可用和 Treasury 拼成“Whop Capital”。

## 依赖及扩展点（分析）

- **B02**：销售付款、退款执行和账单，提供资金来源与交易引用。
- **B10**：KYC/KYB（个人/企业身份核验）、风险控制、冻结释放决定、税款归属。
- **B01** 提供账户和团队权限；**B06/B07** 分别提供奖励及佣金应付义务；**B08** 提供广告支出义务；**B11** 拥有外部接口契约。本卡不决定奖励审核、推荐或广告归因。这些是所需能力，不是整体模块建设先后。
- 扩展点：合作方出款适配、余额用途策略、按国资格、财务连接器、发卡提供方；收益与贷款另成资格门控子域。

## 首个纵向切片与验收候选（未批准）

**切片：已核验商家从一笔模拟销售到可用余额、银行出款及退回。** 不包含真实托管、发卡、crypto、收益或贷款。

1. B09-A01：销售、费用、可用及待结算金额能追溯到同一来源；待结算资金不能进入普通提现可用额。
2. B09-A02：准备金被 B10 持有时不可提现，释放后只增加一次可用额。
3. B09-A03：出款请求重复提交不重复扣款；审核中取消完整恢复相关资金；处理中明确拒绝取消。
4. B09-A04：银行退回生成可追溯事件，金额与余额恢复一致；财务记录不会把充值/内部转账再次记为销售收入。
5. B09-A05：未核验、目的地不符合国家规则及余额不足均被拒绝；显示可处理的原因。

后续候选：企业代付门户 → 受控分账 → 合作发卡 → 单独评估 crypto/收益/融资。不是 Whop 内部实现顺序。

### 发卡合同补充

[美国商务卡条款](https://whop.com/us-card-business-terms/)与[国际商务卡条款](https://whop.com/intl-card-business-terms/)描述以链上抵押品保障的卡账户；美国文本将 Issuer 定义为 Third National，Whop 声明自己不提供信贷。不能据消费页的“花余额”就把所有卡归类为普通借记卡，也不能据它认定存在 Whop 自营贷款。F11 的后续候选切片须涵盖抵押品、偿付、清算及欠款状态；这些本轮只核合同，未测试。

指标候选：到账准确率、出款成功率/耗时、退回率、账务差异、重复资金事件数、受限余额占比、卡拒付原因分布、返现冲正率；收益产品未确认开放前不以 APY 为目标。

地区证据分级：虚拟卡有创建 API 正文；定制品牌和实体卡还有[零工企业页](https://whop.com/network/solutions/gig-economy/)营销佐证，但本轮未核实体寄送、制作费、补卡、开户地区。该页也再次宣传无最低金额的 Treasury 收益，未补足 F14 的资格、资产及收入缺口。
