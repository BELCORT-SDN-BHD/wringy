# B03｜内容、社群、服务与实物交付

证据口径统一见[证据指南](../evidence-guide.md)；演示与真实依赖边界见[共享建设参考](../build-reference.md)；本卡保留的文/API、D/A、营销等本地图例仅作别名，以统一指南为准。API 路径中的 beta 不单独证明预发布；成熟度须依据具体页面正文及版本，未核实则保留未知。

状态：**基于公开研究的候选模块，不是已批准规格，也不是 Whop 内部架构描述。** 核验日：2026-09-10。本文为 B03 唯一功能清单；冲突与商业家族比较见[研究报告](../commerce-delivery-operations.md)。

## 目的、角色与边界

让买家得到所买的内容、社群、服务或实物，并允许商家处理交付失败。角色：商家/讲师/教练/机构、学员/会员/客户、社群管理员、应用开发者、外部服务及物流商。

**拥有概念（未来设计建议）**：会员访问权益、体验实例、商品到体验的交付映射执行、资源访问状态、社群频道/帖子、课程/章节/课时/进度、文件、活动/预约、外部权限执行记录、物流追踪记录。只拥有交付的业务语义；基础身份由 B01、计费合同由 B02、顾客运营与工单由 B04 拥有。商品选择包含哪些体验的配置归 B01。

**范围外**：支付执行（B02）、账本/资金/卡相关依赖（B09）、消费者发现/评价（B05）、开发者应用商店的审核及外部合同（B11）、奖励任务经济、未经证实的仓储/库存系统。

## 正常与失败流程

数字内容：B01 关联商品与体验 → B02 告知付款及计费合同状态 → B03 计算会员权益并核验访问 → 学习/聊天/下载 → 进度和交付事件交 B04。外部软件：有效会员 → 绑定外部身份 → 授权 → 失败进入再同步 → 查看后台结果；再同步文档明确异步执行并记录会员日志，Telegram 排除。

服务：预约或申请 → B04 跟进 → B02 成交 → B03 私有项目空间或外部服务 → 交付材料。实物：B02 支付确认 → 外部仓配收到订单信息 → B03 记录追踪 → 到货或异常交 B04。此处模块分工是分析，不是官方内部调用图。

失败路径必须区分：未付款/权益失效；找错账号；Discord 已绑定其他账号；应用未包含在该商品；上传尚未 ready；课程被删除；测验未达标；物流 unknown、退回、failure 或 error。前述状态有对应 F 行来源。预约冲突/爽约、退款后已下载文件、外部服务宕机后的补偿规则**尚无完整证据**，不能编造自动处理。

## 谁付给谁与依赖

买家为内容访问、单次预约、活动票、专业服务或实物向卖家付费；免费资源可用于获客。支付费、周期扣费交 B02。没有本轮证据能计算课程托管、直播、邮件、储存或每个第三方应用的独立单价及 Whop 利润。实物卖家另与物流/仓配方结算，具体收费合同未知。[卖家责任](https://whop.com/seller-terms/)、[公开费表](https://docs.whop.com/payments-and-billing/fees/fees)（文，2026-09-10）。

| 依赖 | 原因 |
|---|---|
| B01 | 身份、管理权限、商品包括哪些内容；防止同商家不同客户私有门户串访。 |
| B02 | 取得权威支付/计费合同状态；B03 持有访问权益，并依据取消生效时间执行变化。 |
| B04 | 接收交付异常工单并反馈修复结果；为顾客运营提供访问和学习事件。 |
| B05 | 公开试听/商品描述/评价入口；不得由发现结果直接绕过交付授权。 |

补充依赖：B10 的风险/退款裁定可要求撤销访问；B11 管理外部开发者合同与授权；B09 仅在交付场景需要支付第三方时提供资金能力；不在 B03 重建奖励或佣金义务（B06/B07）。这些是所需能力，不是全模块瀑布或 Whop 内部架构。

集成点：Discord、Telegram、TradingView；Zoom/Google Meet；Zapier 和外部仓配；外部 SaaS；嵌入聊天组件。最后一项是可复用聊天技术能力，未发现独立聊天服务收费表。[聊天组件](https://docs.whop.com/developer/guides/chat/quickstart)。

## 第一纵向切片与验收提议

**假设未来建设**：先完成“买一份有访问期限的文件＋会员交流区”，比同时搭课程、视频会议和仓储范围更小；来自 Whop 自身商品组合例子的分析，不是批准。

- B03-A01：测试付款成功且权益有效才可下载文件/进入聊天；同商家未购买其他产品的用户不可串访。
- B03-A02：付款事件重复到达不重复授权；取消期末续费不提前断开现有访问，到期后撤销。
- B03-A03：文件上传未完成不显示成功交付；授权失败可重试，并有客户可见状态。
- B03-A04：客服可定位交付失败并修复；每次动作留记录；修复不修改支付金额。

再扩展切片：课程与进度 → 活动/预约 → 一个外部身份连接器 → 一个运单跟踪连接器。每次先验证访问边界与异常恢复，不把整个家族一次做完。

拟测指标：成交到首次成功访问时间、首次交付成功率、权限修复时间、课程开始/完成率、预约出席率、按时到货率、交付原因退款占比。均为未来建议，无 Whop 实绩。
