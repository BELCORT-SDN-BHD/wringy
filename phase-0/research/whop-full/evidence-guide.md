# 统一证据口径

日期：2026-09-10。适用于总图、四份研究报告和12张模块卡。这里是证据标签的统一解释；卡片中的旧缩写仅作为下表别名保留，不代表另一套标准。

| 统一标签 | 卡内别名 | 证明什么 | 不证明什么 |
|---|---|---|---|
| 官方正文 | 文、D、官方操作/开发文档 | 官方页面描述的功能或规则 | 已实测、所有账户/地区可用 |
| 公开接口 | API、A | 有公开输入、输出或状态契约 | 已有对应界面、接口可在某账户成功运行 |
| 界面截图 | 图、Mobbin | 收录版本的界面或交互 | 当日费率、所有流程和发布状态 |
| 官方营销 | 宣传、M、营销/产品介绍 | 官方声称或推广的方向 | 完整实施、效果、收入贡献、地区资格 |
| 专项条款 | 合同、条款 | 对应主体和产品发布的约定 | 所有客户合同相同、当地法律结论 |
| 明确预发布 | β，须说明正文依据 | 该页明确写明预发布及相关版本 | 仅凭 URL 含 beta 就判定未上线 |
| 未来计划 | 待上线、Coming soon、Upcoming | 该文档所述计划 | 已交付或承诺具体上线时间 |
| 历史资料 | H、历史介绍 | 当时的定位或公告 | 全部内容当前仍适用 |
| 第三方关系 | T、第三方 | 连接或依赖外部主体 | 第三方收入和产品归 Whop 所有 |
| 分析／未知／冲突 | 分析建议、未核、待确认 | 我们的推论、证据缺失或来源矛盾 | Whop 明示事实或创始人批准 |

同一条功能可以有多个标签；这是不同证据维度，不是简单高低排序。公开接口、界面、国家资格、产品成熟度和本轮是否实测必须分别判断。

`/api-reference/beta/` 是当前 API 使用的路径，不能据此标为实验品。Elements 是否预发布，以具体页面的正文和版本说明为准；未逐页核实时写“成熟度未核”，不从目录名称推导。参见 [Whop API Stability](https://docs.whop.com/api-reference/stability.md)。

来源引用量、下载量、索引归类量和实质阅读量不能互换。功能条目是整理责任和范围的单位，**不是工作量、页面数、收入线数或已上线能力数**。每条可能包含多个子能力。
