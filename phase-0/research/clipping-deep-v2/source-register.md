# 来源登记与合并规则

输入文件引用原始来源时，保留：来源标题、发布方、原始URL、发布日期（未提供则未知）、访问日期、适用版本／地区、证据路径和原文定位。引用规范仅用于生产，不是对输入方的新任务指派。

证据类型：官方公开文档、官方营销说明、登录界面直接观察、实际操作结果、外部参考平台、推断、Wringy建议。后两类不能冒充来源事实。

主审合并后建立sources.json，为来源分配稳定内部ID；最终按报告首次引用生成[1]等连续编号。正文可点击编号、对应页短来源说明、末尾完整来源章节保持一致。非公开截图引用本地证据标题与路径，并注明认证访问，不虚构分享URL。对外PDF不暴露个人账号、余额或身份资料；需要时仅裁切相关区域并保留原证据。

重复URL按版本与观察时间核对后再合并。来源冲突记录差异及影响，不能由营销描述覆盖实测，也不能由空白页面否定公开功能。截图无法证明内部风控准确率、后台架构或无条件付款保证。
