# 报告排版与导出方案

A4纵向、正文单栏。白底、深灰正文，有限forest用于表头和必要图线。无装饰照片、渐变、卡片网格或空封面。报告以单标题和实质正文开始。

正文Noto Sans SC 10.5–11pt，行距16–17pt；一级标题17pt，二级13pt；表格不低于9pt，来源脚注8.5–9pt。页边距约18–20mm。中文字体嵌入，正文和表格保留可检索文字。长表重复表头，不把一条规则断成难以对应的两页。

使用现有ReportLab／pypdf及Poppler。最终由report.md与统一sources.json导出，流程图可采用矢量线条与文字，保留图类型和证据说明。对外截图只采用真实证据及必要隐私裁切，禁止AI图像和虚构界面。

编号引用链接到原始资料，文末完整来源清单。页码可作阅读导航，不添加装饰页眉。约10–20页按内容决定，不为凑页增加摘要或重复表。

仅准备版式，尚不生成研究PDF。首次实际PDF创建前执行一次PDF操作marker；当前未执行。导出后核对页数、引用编号、URL注释、中文提取及表格边界，Poppler逐页渲染检查。最终输出report.md、PDF和检查回执。
