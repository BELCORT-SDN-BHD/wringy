# Wringy 内容奖励：竞品运营与商业规则比较

研究日期：2026-09-13（Asia/Kuala_Lumpur）。范围：商家购买分发、创作者凭合格播放取得奖励。采用本次公开网页检索、官方帮助、条款和定价；未注册、联系厂商、登录或使用私人浏览器。本稿不覆盖主任务负责的剪辑机制细拆、社交接口可行性及逐屏浏览器验证。

**结论：以 Content Rewards 当前规则作完整交易参照，以 Vyro 作预算与待结算参照，以 Clipster 作托管运营参照，以 Clip.farm 作另一种奖金池定价参照。** 另纳入 MakeClout／Clouted 的社群招募和计量异常说明。菲律宾 Clipfarm.ph 另外保留为较低置信度的本地支付参考，不冒充已经验证的成熟平台。Socialplug 排除。选取依据是不同的购买、审核和付款安排，不是客户 logo 或宣称的观看总量。

标记说明：**事实**只表示官方确实这样写，不表示已验证履约；**推断／建议**是本研究判断；**未知**表示公开证据不足。CPM 指每千次播放的价格；在本文中，原始播放、合格播放和最终有钱可付的播放并不相等。所有来源编号见同目录 `sources.json`，正文链接可直接复核。

## 1. 研究边界与基础核对

已读 [旧报告](../../whop-wringy-blueprint-v1/report.md) 与 [后续首发研究](../../../deliverables/content-rewards-business-v1/research/findings.md) 作为指针；核心现价均重新查询。以本次任务的创办人指示为约束：Content Rewards 首发，Prototype＋可用 Beta 研发上限 RM50,000，2–4 个月，EN／BM／中文，沿用已批准的 Linear／shadcn 方向。本稿不批准新规格、不改收费决策、不引用旧大预算作为现状。

最大风险：把不同合同的“按播放付费”归为同一规则，会让 Wringy 承诺自己无法兑现的报酬。尤其要区分固定 CPM、预算不足时折算，以及固定池按份额分配。

交付检查：每个平台均覆盖审核、计量、收费、付款、活动管理及 Wringy 启示；不能核实的字段明确留空。工作目录不是 Git 仓库（本次 `git status` 返回 not a git repository），因此没有创建分支或声称完成跨厂商代码审查；仅新增本工人的两份研究文件。产品批准链与可用 Beta 开发验收由主任务处理，本工人不据研究稿开始实现。

## 3. Whop／Content Rewards：当前与旧版要分开

**事实：** 2026-09-03 的 CR 组织条款规定：旧 Whop 内嵌体验内注资运行的活动，继续适用用户当时接受的旧品牌条款；新活动和其他事项适用现条款。CR 管活动、投稿、验证与奖励逻辑；Whop 管资金处理，不能把 Whop 自有 Program 条款替换成 CR 的历史合同。[W03](https://contentrewards.com/brands-terms)

| 事项 | 当前公开证据 | 对旧资料的处理 |
|---|---|---|
| 品牌费 | 标准10%、认证8%；最低活动预算 US$1,000，可补资，无订阅 [W02] | 费率不等于 Wringy 已批准报价 |
| 创作者费 | CPM 固定10%；按帖／周期预算达 US$5,000 免创作者费，否则10% [W01] | 不再用旧7%或阶梯；当前 V2 正文也已改成此规则 [W05] |
| 时间 | CPM 从批准开始赚7天，再持有3天；免费且无最低额转至 Whop 余额 [W01] | 不是第十天保证银行到账，更不是所有支付路径免费 |
| 审核 | 现条款为人工批准／拒绝，没有自动批准；要求必须写在平台内 [W03] | 不沿用旧教程的48小时自动批准；Whop 自有 Program 则另保留自动处理权 [W06] |
| 产品变化 | V2 公告新增自身组织权限、预审版本与反馈、周期合作及可解释的钱包状态 [W05] | 公告日期为8月19日，正文会更新；发布日期不是内容快照 |

来源：[W01 创作者定价](https://contentrewards.com/pricing/creators)、[W02 品牌定价](https://contentrewards.com/pricing)、[W05 V2 公告](https://b4e0vdqv6zgqeqj4pfgm.apps.whop.com/articles/v2-is-here)、[W06 Whop Program](https://whop.com/content-rewards-terms-of-service/)。W06 明确卖家支付给参与者金额的10%为其费用；不能把该费基移植到独立 CR 账单。

**审核与管理事实：** 当前 CR 的风险分数用于人工决策，自动标记不等于拒稿；待审投稿未处理完不能申请退款，已产生的应付款优先。活动暂停不取消已批准稿的结算。[W03](https://contentrewards.com/brands-terms) 风险标记每稿一次申诉，目标10个工作日回复；普通品牌拒稿则由支持与品牌复核，不能保证翻案。[W04](https://contentrewards.com/terms)

**矛盾与未知：** 品牌定价表写没有其他费用，但组织合同与 V2 另列支付处理费；V2 说平台费从预算内扣。最终收费分母、税和处理费应以付款明细确认，不能直接把两边10%相加当总预算20%。没有取得旧活动当时接受的合同全文，也没有验证当前批量审核和投稿 CSV 是否已经补回；8月公告称暂缺，不足以断言今天仍缺。[W02/W03/W05]

**Wringy 建议：** 借组织归属、规则版本、审核理由及申诉记录；不把周期合同、复杂代理树和多种费用同时带入首发。例：一条 BM 投稿被判不合要求时，应能指向其加入时看到的那条规则，而非审核员后来在聊天里补写的要求。

## 4. Vyro：最有价值的是“看到收益”与“能拿到钱”之间的条件

**事实／活动管理：** 品牌先设预算、素材、规则、平台与截止时间；品牌页称最低 US$5,000，可暂停、补资，结束后退未用预算。平台宣称 AI 加人工审稿，并提供播放、花费、创作者、平台和时间维度分析。[V01](https://vyro.com/for-brands)

**事实／计量与付款：** 提交后起算播放，即使尚未审核；每小时刷新，批准并达门槛才有资格计酬。活动结束后复核才将 pending 转 available；主页写最低提现 US$10、每周一次，经地区可用的 Stripe／PayPal。[V02](https://vyro.com/) 帮助页列每稿最低5,000播放、最多计100万合格播放；付款专页写结束后通常7–10天可用，不能与另一条“7天验证”当成精确同一承诺。[V03](https://vyro.com/help/earnings-and-payments) [V05](https://vyro.com/help/earnings-and-payments/when-will-i-receive-my-earnings)

**事实／预算边界：** 接近预算耗尽时，奖励按比例分配，所以创作者实际收入可低于页面 CPM。不能拿“合格播放×标价”直接作确定应付款。[V04](https://vyro.com/help/earnings-and-payments/why-arent-my-earnings-matching-the-cpm-on-the-campaign)

**合同重要补充：** 2025-12-20 创作者条款允许客户资金尚未结清时发布活动；资金未到账可取消且不付款，即使稿已批准、收益已累计。合同也允许不合格或违规奖励追偿，支付方可能扣费用，并不保证资金可用日期。这是现公开合同的条文，不代表本次观察到实际欠付事件。[V06](https://vyro.com/clipper-terms)

**未知／佣金：** 本轮未找到品牌平台抽成或创作者平台抽成的统一公开百分比；免费注册不证明奖励无扣费。马来西亚完整出款路径、按比例分配精确时点和算法也未验证。营销页“先注资”不能证明平台会等到账后才开放投稿。

**Wringy 建议：** 优先学清楚分开预估、确认、可提取、已到账；避免把未到账品牌资金包装成可兑现奖励。例：若奖励池只剩 RM100，两条稿按标价各赚 RM80，先决定是否各得 RM50、先到先得，或预留名额，再开放活动。这里是解释预算冲突的假设，不是 Vyro 的完整算法。Wringy Beta 应选定一种规则并展示，不在结算时偷偷打折。

## 5. Clipster：值得学习托管分工，不能照抄市场与语言要求

**事实／商业与管理：** 官方品牌页按已验证观看收费，Starter 展示 US$3K–10K；大额承诺降低费用但未列统一抽成百分比。服务包含策略、招募、审稿、付款和报告，仪表板可追溯到每条已批准帖；宣称机器筛查加人工。页面特别强调音乐推广和 logo 分发。[C01](https://advertise.clipster.gg/)

**事实／审核与测量：** 全局规则禁刷量、付费推广及互动群，规定活动结束后保留帖子至少30天；要求公开数据，并设0.2%基础互动门槛、较高 CPM 活动可到3%。音乐条款明列不接受 SEA／RU／IN 语言内容，另有内容类别限制。因此 BM 活动不能直接套其音乐规则。[C02](https://www.clipster.gg/general-campaign-rules)

**事实／付款：** 创作者条款把品牌批准设为奖励成立条件；付款至指定金融账户，例如 PayPal。若赚取后30天内未设置收款账户，条款称放弃该笔费用权利。YouTube 数据说明列公开视频、频道与播放统计。[C03](https://www.clipster.gg/creator-tou)

**责任差异：** 品牌条款说 Clipster 没有义务监测或审核活动，费用由活动内或书面指定、首日起30天到期；终止不保证退未用预付费用。[C04](https://www.clipster.gg/brand-tou) 这与“全托管审稿”营销不是同等承诺。需要区分销售服务范围与合同责任，不能因此断言某一方从不审核。

**未知：** 统一平台费率、创作者净奖扣费、刷新间隔、最终合格播放公式、普通拒稿申诉时限、MYR到账均无充分证据；广告页的超低成本案例也不是 Wringy 获客报价。

**Wringy 建议：** 把“谁审、按哪版规则、多久处理、能否复核”写清楚，保留逐帖链接与理由；不复制30天未绑账户即失去收入的安排。例：本地小商家购买 BM 传播时，运营应该按已接受的 BM 简报审核，而不是导入全球广告网络的语言排除清单。

## 6. Clip.farm：另一种价格承诺，不是固定 CPM 的换皮

**事实（官方搜索索引）：** 法文首页描述品牌设置固定奖金池和时长（一天至一月）；创作者在 TikTok、YouTube、Instagram 或 X 发布，结束时按观看份额分池。页面一处写80%给创作者、20%平台，付款通过 Stripe 银行转账；另一处却写100%预算分给创作者。直接打开首页未提取出正文，故只作为官网索引中的产品主张，不把20%作已验证账单。[F01](https://clip.farm/)

**事实（条款正文）：** 2026-06-09 条款声明按真实自然观看奖励，疑似机器流量先拒稿并调查，严重违规可没收未付收益；即使直接向社交平台购买推广也禁止。真实性决定被写为最终决定。转介佣金基于 Clip Farm 实收的合格剪辑净收入，费率、周期和门槛由平台决定，不能与20%平台份额混同。[F02](https://www.clip.farm/terms)

**计量与管理：** 隐私声明列 YouTube／Twitch／TikTok 的公开或授权观看数据用途；没有披露合格观看公式和误判率。[F03](https://www.clip.farm/privacy) 公开材料支持设置总池、时长、来源素材和投稿，未核实内部角色、批准队列、退款及补资体验。

**未知：** 首页与旧式英文条款是否已同步到同一产品版本；平台20%和100%分配矛盾如何解释；审核时限、申诉路径、MY 支持、失败出款处理均未确认。不要引用同名菲律宾网站去填空。

**推断／Wringy 建议：** 固定池使品牌支出确定，但创作者每千次播放的实际收入取决于其他人的表现。假设净创作者池 RM800、A占总合格观看25%，则A得 RM200；他之后被别人追过，份额会降低。这是模型示例，不是已核实的 Clip.farm 算法。首发优先保持明确的合格播放费率；如果未来引入竞赛池，另设产品类型，并标“预计份额”，不标确定时薪或固定 CPM。

## 7. Clipfarm.ph：本地化参考，证据不足以证明规模与履约

**事实（官方定价索引）：** 页面写最低 ₱50,000、品牌预算外加10%、创作者不收费、平台吸收出款费用；批准稿按经去重和机器流量过滤后的观看计酬。列审核队列、投稿追踪、CSV 与分析；每周 GCash／Maya 出款，批准后通常不足7天，批次结束后多数48小时内到账。可暂停／关闭，已批准稿按约定执行，待审稿释放。[P01](https://clipfarm.ph/pricing)

**未知：** 直读首页和定价均超时，未验证经营主体、支付合同、生产使用量、实际到账或退款履约。该页面不是独立证明“本地电子钱包＋零创作者费用”有利可图。作为较低置信度补充；主结论不依赖其成熟度。

**Wringy 建议：** 可借鉴“奖励池＋品牌费＝总支出”的表达与固定出款批次。例：假设池 RM1,000、品牌费10%，总额 RM1,100，不应把 RM1,100 全写成创作者预算。10%仅为说明，不是 Wringy 定价；GCash／Maya 也不能据此替换为未经验证的马来西亚付款服务。

## 8. MakeClout／Clouted：直接参照，但以应用剪辑条款为准

用户补充的 Clipping 品牌页页脚仅作为发现线索。本节全部使用 MakeClout／Clouted 自己的页面，没有采用 Clipping 的竞品比较作为证明。

**事实／身份与匹配：** MakeClout 官网将剪辑者导向 app.clouted.com；应用公开登录页明确按观看赚钱。故纳入其剪辑奖励计划，不把 Clouted 的一般 UGC、广告与网红合作都视作同一个按播放产品。[M01](https://makeclout.com/) [M02](https://app.clouted.com/login?callback_url=/) 品牌剪辑页描述交素材、按行业选创作者、逐稿审质量与品牌适配，再从看板追踪；24–48小时上线是其营销承诺，未实测。[M05](https://clouted.com/solutions/clipping)

**事实／审核和计量：** 应用条款更新于2026-03-04，要求遵循活动简报，由 moderators 最终批准或拒绝，并保留活动要求随时变更的权利；收益验证前为估算，只有 Accepted 投稿可获付款。观看定期刷新，坏链接、私密账号、地区限制与格式错误会阻止追踪，重复链接可拒收；禁购买播放和虚假互动。批准稿在活动结束后60天内不得删除。[M03](https://app.clouted.com/terms-of-service)

**事实／付款与管理：** 应用条款把出款安排和最低门槛交给公布的计划，但该条款未写具体门槛金额。MakeClout 官网写每周或每两周付款、通过 App／Discord 找活动；FAQ 宣称多数剪辑者加入后7–14天取得第一笔付款。它们不构成每一稿批准后7天到账的保证。[M01](https://makeclout.com/) [M04](https://makeclout.com/faqs)

**未知／佣金：** 未获得统一品牌费率、创作者抽成、最低品牌预算、具体提款门槛、支付方式、MY 支持、争议时限或合格播放算法。没有从月赚 US$1–5K 的营销数字反推 CPM。MakeClout 网站 `/terms` 的搜索索引仍描述短信订阅，直接打开仅提取通用招募文字；本次采用应用登录页明确链接的剪辑条款，不把短信“免费”当剪辑无佣金。[M06](https://www.makeclout.com/terms)

**Wringy 建议：** 最值得借的是让创作者及时知道投稿为何无法计量，以及把社群招募接回有记录的任务工作台。例：BM 创作者发来私密帖链接，应显示“无法读取，请改公开后重新核验”，不要只显示0播放。不要复制活动规则随时改变、审核员最终决定却不提供明确复核流程的组合。品牌托管可人工先做，但这不是省掉计量与账目证据的理由。

## 10. 给主任务的证据交接

- **不能混用的合同：** Whop Program、旧 Whop 内嵌 CR 已接受条款、当前 Content Rewards Inc 条款是三个对象。现 V2 正文已是固定10%，旧搜索摘要不是现价。
- **最重要的新对比：** Vyro 合同允许资金未结清先开活动，并把资金不到的风险传给创作者；Clip.farm 是池分配模型；Clipster 的音乐语言限制与 Wringy 的 BM 首发方向不兼容。

- **有意未做：** 私人浏览器、账户与社交授权、付款实测、厂商接洽、主任务的接口与剪辑机制研究。不存在假装操作过的审核按钮、到账截图或后台权限结论。
