# Creator Rewards 经济与控制合同

建议 Wringy 先冻结“哪一笔钱因什么证据归谁”，再设计按钮。最大风险是把 Whop 自有 Program、Whop 内嵌应用教程和新版 Content Rewards（CR）web 合同拼成一种现行机制。三者在费率、审核门槛、自动审批上有实质差异。

证据截至2026-09-11（马来西亚时间）。下文“声明”指官方合同/页面所写；“观察”只指本轮读取的公开页面；“推论/提案”不代表已实现。R01/R02/R03标注2026-09-03更新，保留旧Whop活动原接受条款，不能追溯覆盖所有旧余额。未获取真实用户接受副本、后台裁决或银行到账。本文为研究输入，不批准任何Wringy资金规则或产品实现。

## 1. 费用、门槛与时间合同

CPM指每千次合格播放计酬；毛奖励指扣创作者手续费前金额；净奖励仍不等于扣完银行、换汇与税项的到手款。下表为当前CR声明，除特别注明均非实际交易验证。

| 项目 | 可确认 | 分母、边界或未知 |
|---|---|---|
| 品牌平台费 | 标准10%，CR认证8%；仅已交付/批准工作收费 [R04] | 公告称从已注资预算扣 [R06]；当前页面未明确是毛奖励加成，还是含费支出内扣。精确等式未知 |
| 注资处理费 | 合同约注资金额2.7%＋每笔小额固定费，逐笔列示，非CR收入 [R02 §4.2] | 当前合同未定固定项；R06的$0.37不能升级为所有渠道现价 |
| 创作者费 | CPM固定10%；按帖/周期活动预算低于$5,000为10%，达到$5,000为0% [R05] | 分母是创作者奖励；CPM无大额免收费；补资跨线是否追溯未知 |
| 活动最低预算 | 三类均$1,000；周期金额须小于总预算 [R01 §6] | 页面美元标价，不是马币报价；币种替代及换汇规则未验证 |
| 单稿最低/最高 | CPM活动可设最低应赚金额、最高奖励 [R01 §6.1] | 不等于统一观看数，也不等于提现最低额 |
| 按帖 | 固定奖励；可设观看门槛及品牌监测期，未达标预留返预算 [R01 §6.2] | 非CPM持续赚取；批准后结算与监测未完成的先后须澄清 |
| 周期合作 | 按周期支付，周期末结算 [R05] | R06另描述按比例/全或无、周期预留；合同按投稿批准预留 [R01 §6.5]，粒度不同 |
| CPM时钟 | 批准起7天计酬＋3天等待；按帖批准后不久、周期末结算 [R05；R02 §6.2] | 可调整；风险标记暂停结算。不是全模型7＋3，也不是十天银行到账 |
| 转出最低额 | 转Whop余额无费、无最低额 [R05] | 仅这段转移；外部提款依Whop路线与收费 [R10] |

**公开活动观察**：Tizz各平台展示$2/千次、$10最低/$200最高；Fishtank同活动Instagram与TikTok的费率和上下限不同。[R12–R13] 这些只是活动展示值，不能倒推出默认值、实际扣量或所接受合同版本。

## 2. 七个应拆开的判断

| 判断 | 当前声明与负责人 | Wringy产品含义（提案） |
|---|---|---|
| 内容审核 | 品牌人工审批；Pending无自动批准 [R02 §6] | 显示等待时长、负责人、理由 |
| 风险审核 | 第三方辅助评分，最终人为决定 [R03 §6] | 风险状态独立，不把“标记”显示为“作弊成立” |
| 播放计量 | 社交接口数据参与核验 [R03 §4] | 显示数据截至时间与缺口 |
| 奖励累计 | CPM逐步扣预算；按帖/周期批准预留 [R01 §6.5] | 区分估算、预留、已确认应付 |
| 等待验证 | 开放风险标记暂停结算 [R02 §6.2] | 显示暂停原因与下一步，不能只重置倒计时 |
| 结算入余额 | CR维护应付账本 [R01 §16] | “可提现”是财务状态，不是品牌批准别名 |
| 外部付款 | Whop及其条款处理提款、相关身份核验 [R01 §3] | 请求、处理中、成功、失败分别留记录 |

草稿通过不是公开帖最终通过。[R01 §8] 风险申诉每稿一次、目标10工作日答复；普通拒稿由品牌决定是否改判。未结算可因成立的拒绝/标记逆转；已结算不走该流程，但确认欺诈损失等可另抵扣。[R01 §§10–13] 因此“审核通过”“风险解除”“不可追回”不能相互代替。

品牌退款须清空待审、先偿创作者；余款可退，可酌扣未花预算最多20%，处理费不退，审核5–7工作日。[R02 §10] 暂停活动不取消已批准款。[R02 §6.6] 普通退款与有依据的逆转是不同操作；卡组织拒付又是第三条路径。

**可知的风控边界**：公开政策只披露投稿/账号信号、0–100分、阈值分流、人审；不公开供应商名称、权重、校准误差。[R03] 分数75不能翻译成75%假观看。首页“每次观看都检查”与FAQ“外部独立核验仅部分代理beta”并列，后者限制了可证实范围。[R09] 没有证据支持某种固定抓数频率、观看去重算法或马来西亚地域识别准确率。

## 4. 经济公式：全为假设演算

以下是**可供Wringy选择的合同写法**，不是复原CR账单。金额用假设RM，无真实交易、无汇率换算。设G为毛奖励，b为品牌费率，c为创作者费率；P为外部支付费，W为提款费，X为换汇费。平台收入是收费收入，尚未扣运营成本，不能称利润。

推荐明确“品牌费以G为分母”：F品牌=bG；F创作者=cG；平台收入R=bG+cG；创作者净奖励N=G(1−c)；品牌总支出T=G+bG+P；外部到手=N−W−X−适用税项。未花且可退预算不算收入。

| 全假设、单次已赚部分 | G | b | c | P | 品牌T | 平台R | 创作者N |
|---|---:|---:|---:|---:|---:|---:|---:|
| CPM：50,000次合格播放×RM4/千次；最低RM20、上限RM200已满足 | 200 | 10% | 10% | 6 | 226 | 40 | 180 |
| 按帖：一稿RM300，假设无播放门槛 | 300 | 10% | 0% | 9 | 339 | 30 | 300 |
| 周期：RM1,200/4稿，3稿合格，假设按稿等权比例 | 900 | 10% | 0% | 27 | 1017 | 90 | 900 |

首行平台费40/G=20%，但40/T≈17.70%；不能把“双边各10%”称品牌总支出的20%。若采用含费支出S内扣模型，则F品牌=bS、G=(1−b)S、R=bS+cG；假设S=RM1,000、b=c=10%，得G=900、N=810、R=190，品牌总支出=1,000+P。两种分母不同，不能只写“抽10%”。R02/R04/R06不足以裁定CR究竟怎样逐分入账。

CPM提案可写：候选毛奖励=min(单稿上限, 合格观看数×费率/1000)；低于最低金额是否清零或留待补量必须另定，不能默认为超过门槛只付超出部分。预算可用额小于候选额时，先应用公开分配规则再确认G。周期若改为全或无，上表示例会变成0，故必须在参与前固定比例规则及交付权重。

## 5. Wringy规则决策与八个边界场景

**建议首期**：Belcort只开放一种已冻结的CPM经济合同，按帖/周期保留产品规划，避免同时调试三套资金条件。建议起算从合格链接提交时开始、固定自然时长并记录批准前基线，审核不改变计量边界；这是Wringy提案，区别于CR批准日起算。具体7天计量/3天验证可作为试点参数，不作永恒常量，须用数据到达延迟和争议样本验证后批准。

审核服务时限有两种选择：推荐48小时内人工首次处理，逾时升级平台运营、暂停新投稿入口，不自动批准；备选3个马来西亚工作日适合低运营投入，但创作者等待更久。两者是提案而非Whop现行服务承诺。申诉建议2个工作日确认受理、5个工作日首次实质答复；延长须说明缺证和下次更新日。Belcort作为品牌时，品牌审核与平台申诉应由不同人员处理，避免自己裁定自己的争议。

| 场景（均为Wringy验收提案） | 应冻结的处理 |
|---|---|
| 1. 两稿同时争最后RM100 | 已确认款不可争抢；同一计量批次按合格应赚比例分配，最小货币尾差按稳定投稿顺序；写明截止批次 |
| 2. 审核超时，视频已爆量 | 从提交基线计量；超时升级人审；不自动接受、不延后起算以少付 |
| 3. 草稿通过，发布版漏广告披露 | 关联批准稿版本；指出差异允许补正；补正计量起点事先写明 |
| 4. 临近结算才有风险标记 | 暂停争议部分结算；保留计量数据；人工解除后依原窗口补算，不凭分数扣百分比 |
| 5. 品牌在外部文档增加要求 | 旧投稿按参与时平台版本审核；新规则仅新参与者适用并记录确认 |
| 6. 断开社交连接、删帖或接口故障 | 三者分开标记；最后有效快照保留；补证期限与补算规则明确；故障不自动判作弊 |
| 7. 品牌停止活动并申请退款/拒付 | 停新稿，先清应付/争议准备金；普通退款、风控逆转、银行卡拒付分账；不得抹掉已确认债务 |
| 8. 周期只交3/4，或补资跨免手续费线 | 后续模式上线前冻结比例/权重；费率按接受版本锁定，新优惠是否追溯须明示，禁止静默改账 |

必须由Founder决定并进入正式规格：合格播放定义及允许流量、时间端点/时区、最低额未达处置、预算并发分配、费用分母/舍入、付款暂停与追索权限、普通拒稿独立复核、发布内容保留期限。界面建议把审核、风险、数据完整性、奖励状态分开显示；沿用已批准Linear＋shadcn方向。EN/BM/zh-Hans-MY共用规则版本、金额和时间源；翻译不能分别产生三个经济合同。

## 6. 主报告需保留的缺口

未知不等于不存在：新CR队列实现、计数与合格数转换、批准前观看、7天后累计、风险期补算、预算并发、周期预留粒度、补资跨费率线、完整处理费报价和马来西亚提款路线均未证实。不得用宣传统计替代反作弊效果或实际收入。

建议补缺成本（估算）：Founder＋运营2小时冻结首期经济合同；Belcort运营1–2工作日整理8类合成账例与可取得的真实证据字段；支付供应商确认MYR收付、换汇、退款/拒付责任另计。当前任务未进行交易、注册、联系支持或权限调整，无法以实测消除这些缺口。工程地基与批准链由主报告汇总，此工作者只交研究文件。
