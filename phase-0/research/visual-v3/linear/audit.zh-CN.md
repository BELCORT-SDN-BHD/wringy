## 参考事实：应学结构与语义，不只学灰线与小字号

**工作区不是一种固定三栏。** [团队 issue 列表](https://mobbin.com/screens/9ec39891-cdbb-4d57-b0c6-de43f82c5f4e)将全局入口、工作区入口、团队入口分开，主面板内再放团队名称及 All issues/Active/Backlog；另一批截图将 Active/Backlog 放在左栏。 [完整 issue 详情](https://mobbin.com/screens/6e105b56-a616-497c-87bc-70fdeaf31048)是左导航、中央正文、右属性；[Inbox 内详情](https://mobbin.com/screens/beb9d6b3-ec34-46d7-9332-320fcb32a338)则额外保留通知队列。v2 引用的第一张实为 Inbox 语境，不能由此归纳所有工作区必须“列表+右详情”。

**密度来自字段选择和对齐。** [Display 面板](https://mobbin.com/screens/815793b1-5c75-43ac-94c7-93380781e337)显式列出 List/Board、Grouping、Ordering 和显示属性；[项目列表](https://mobbin.com/screens/937fc32e-04c6-4c39-bcd6-17a42b4fe83c)用细分隔、状态组头和固定元信息位置形成扫读路径。截图只支持相对层级：标题更重、ID/时间更弱、行紧凑；没有可验证的字号、行高、侧栏宽度、字体名或中文排版值。隐藏字段不等于响应式。

**看板有自己的信息预算。** [浅色看板](https://mobbin.com/screens/fc208a44-dbf9-4f79-b9b0-db57f9840964)显示状态列、计数、卡片、隐藏列和筛选清除提示；[深色看板](https://mobbin.com/screens/720724d3-f686-457f-8c00-fa7efa409b12)靠画布与卡片的微弱明度差、彩色小标记建立层级。前者可见悬浮卡片，但未操作拖放，不能声称验证了拖拽/键盘/失败状态。两张内容不同，不作为同场景主题像素配对。

**创建、编辑属性、筛选必须分开。** [创建弹窗](https://mobbin.com/screens/9ae1ad02-5e59-4079-9eba-21589c0fe211)保留原工作区背景，优先标题/描述，属性行与附件、创建动作分区。[issue 状态菜单](https://mobbin.com/screens/744b87f4-4e13-488a-9338-2ca18b39bef1)有状态图形、当前勾选与快捷提示；[负责人菜单](https://mobbin.com/screens/53aafc60-0736-490f-bd89-40bfb76c8332)有搜索、无负责人、头像与人名。与此不同，[状态筛选菜单](https://mobbin.com/screens/d1d26f7d-e1e5-490f-ab4f-c96dd12854c1)从属性菜单再进入子菜单，筛的是集合。[优先级编辑菜单](https://mobbin.com/screens/c2cbaff3-1a8d-4fd4-af9a-c5c31533082c)实际属于项目，issue 查询没有得到同等可靠的开放菜单，不偷换对象。

**搜索不是命令执行。** [全局搜索](https://mobbin.com/screens/a2f96ae5-202c-4747-a959-d33d7e5c0f72)是全页输入、对象类型分类与结果；[无结果](https://mobbin.com/screens/d0b98680-66e2-47d4-9dc4-28bc9450c27f)保留查询。[命令教程](https://mobbin.com/screens/1e783aca-8b8e-4ae5-994d-284a8ddae491)能证明截图引导 Command+K；[快捷键帮助](https://mobbin.com/screens/b6cf0a0b-0705-46ac-bd5f-63172576c627)是右侧抽屉。多个命令查询实际返回 Ask Linear、图标选择器或帮助，不能用它们证明开放命令面板的分组、宽度或交互。

**项目与设置的正文应有阅读宽度。** [项目 Overview](https://mobbin.com/screens/f4cd410f-b1b4-49fe-a247-80071f69ba1e)先对象名称、摘要、属性与资源，再长描述；[最新更新](https://mobbin.com/screens/e88b6bd7-3d4b-4e1e-8cd7-a9d2a6852795)是另一内容块，右侧进度/活动有对象含义。[偏好设置](https://mobbin.com/screens/aa0b9e71-c5a0-4245-b30a-ee5059de6235)切换独立导航，内容限宽，标签/辅助文案在左，输入/开关在右；[Profile](https://mobbin.com/screens/a4e7fb71-dd94-4c1d-a5af-f032e03a10a9)把离开工作区单独放进危险区。静态图不证明所有字段即时保存。

**确认要说明对象和后果。** [删除 issue](https://mobbin.com/screens/9a1bd072-26d6-493a-a8ad-a779e43dd605)点名对象与子项并说明恢复期；[删除 label](https://mobbin.com/screens/9e314711-6928-490b-9ac5-96afebb32e22)说明关联影响和不可撤销。截图中的30天仅是所见文案，不是经官方核对的现行服务政策。 [通知删除反馈](https://mobbin.com/screens/14cbb61d-2120-46fa-b29c-b7678e4b85cc)则有 Undo toast，不能由此让所有删除都不确认。

**空白有不同含义。** [首次无项目](https://mobbin.com/screens/5273571d-4f58-410a-97a0-f6018dc8b80f)有图、解释、创建与文档；[筛选无匹配](https://mobbin.com/screens/90b0ca17-b70a-425c-b28b-ce934231b2b9)保留筛选、隐藏计数与清除入口；[Inbox 未选择](https://mobbin.com/screens/18c6955a-c42f-4cc1-9aa2-0276456720fb)仍有7条未读，绝不是无通知；[模板首次空态](https://mobbin.com/screens/b68d8044-6bd7-4095-b752-f1db068e9a30)只是简洁文本行。[工作区表单](https://mobbin.com/screens/5c68cc35-0d93-47ba-b27e-ed4efe90b75c)只验证了字段必填错误的视觉形式，不能推广成网络错误/重试证据。

**主题和平台不能偷换。** [主题设置菜单](https://mobbin.com/screens/59e38375-a880-466b-8f29-b6e59358c61a)有系统偏好和多种命名主题，并不只浅/深两个选项。[iOS 详情](https://mobbin.com/screens/ed788cb0-3715-4383-9cbd-783d2a55bdf8)把属性移到标题下，保持单栏和底部评论；它是原生 Linear Mobile，不能推导 Wringy 网页断点或当前网页移动设计。字体、主题准确数值、hover、focus、转场时长、触控尺寸及可访问性都未从截图验证。

## 给 Wringy 制作的建议：产品改编，不是 Linear 证明

建议先产出一组相互一致的工作区设计，再扩展表单：审核队列默认、选中作品详情、无匹配、未选中、属性浮层、审核确认。这些是为了让品牌审核者看清作品、版本、期限与决定，不要求功能对齐 Linear。具体例子：清除“待最终审核”筛选应恢复可见作品集合，不能顺便改变作品审核状态；这是 Wringy 契约，需要 PRD 或设计规格确认，不能由 Linear 菜单授权。

v2 的“原稿可发布→最终作品获批→奖励符合付款条件→银行出款证据”分层必须继续由产品规则定义。借用 Linear 的状态小图标与简洁属性行，不等于可以把最终审核通过显示成已付款。负责人、优先级、看板、全局命令、通知系统和主题切换在本报告中都只是组件参考；只有 Wringy 的实际产品需要且获准时才设计为功能。尤其不因看见项目进度图，就向审核台加虚构数据。

建议制作审阅时固定一个浅色应用框架作为主参考家族；将其他结构标为变体证据。版本元数据缺失，不能把所有截图声称为同一版。先验证真实中文作品名、两行创作者信息、日期与条件奖励的内容负载，再确认密度。无需为了“像 Linear”压缩到英文截图的小字感。颜色、圆角、字体和断点都应在 Wringy 的 canonical tokens 中独立定值，经审阅后再同步下游；本研究没有写这些值。

## 给 YC deck 制作的建议：采用阅读层级，不借用功能背书

以下均为 Wringy 制作建议，不是 Linear 研究事实或 YC 官方要求：

- 产品页呈现一个清楚的审核任务：作品队列→选中详情→明确下一步。保留足够的应用框架证明这是工作区，但将关键标题、条件奖励和动作做到演示阅读距离可见；不要把整个桌面密集列表缩成一块小图。
- 可用同一概念样例的局部放大解释“原稿审核与付款事实分开”，无需添加图表或堆十个组件证明成熟度。
- 保留 deck 级“概念示例”标记，所有作品、客户名、金额、状态同 v2 canonical 样例源；不将 Mobbin 样例中的完成数或 Linear 功能写成 Wringy 业绩。
- 参考截图用于内部研究，不作为 Wringy 成品截图。暖白、Citron 与字标方向由 Ramp/品牌任务另行整合，本 worker 没有研究 Ramp，因此不对其证据作补充或批准。
