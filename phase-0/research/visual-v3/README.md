## 这次修正了什么

Ramp的截图显示多种表达方式：白底产品画布、深色内容块、摄影案例、编辑式正文和不同密度的目录。不能把一张首屏的底色、留白和按钮概括成所有页面规则。不同版本的归属尚未确认，也不能仅凭颜色判定新旧。

Linear的详情页和通知详情不是同一种布局。列表要便于扫读，完整详情要给作品与说明足够空间，设置页则需要限宽表单。筛选改变可见集合，属性菜单改变对象信息，两者不能只因长得像就用同一个交互规则。

截图可以支持构图、层级和组件语义的观察，不能验证源字体、精确色值、断点、动画时间、权限或付款规则。新Wringy稿中的这些选择都是本项目适配提案。
