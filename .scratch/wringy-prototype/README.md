## 执行入口

首票可认领。后续票只有前置状态完成且实际输出可用才解除阻塞；ready-for-agent标签不是已完成标记。当前路径是线性依赖，因为每票都消费前一票建立的业务记录，而不是为了追求并行人为分割UI/API。研究或静态资源准备可并行，但不重复修改共享状态模型。
