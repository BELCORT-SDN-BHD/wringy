# 商家能配置、预览并模拟发布活动

Ticket: M1-02
Milestone: 三端交互原型（M1）
Label: ready-for-agent
Status: blocked
Assignee: none

**What to build:** 商家从自己的活动列表创建草稿、按默认值配置并预览，经模拟就绪检查发布；发布后同一记录出现在公开活动目录。

**Blocked by:** [用户能浏览公开活动并进入模拟工作区](./01-browse-and-enter.md)（01）

**Spec:** [首阶段原型规格](../../../phase-0/foundation/milestones/prototype-spec-v1.md)

**验收追溯：** P02, P10, P11。这些是原型验收，不代表对应生产业务验收已通过。

## 验收条件

- [ ] 默认值承接已批准规则；缺资金或数据就绪提示时不能模拟发布；提供演示工具设置就绪条件。
- [ ] 最低金额高于封顶时阻止发布；高观看门槛配较低封顶可成立，预览解释封顶结果。
- [ ] 草稿编辑、预览、发布与活动详情数值一致，重复点发布不重复生成活动；刷新保留状态。
- [ ] 费率/门槛/封顶/计量及申请期限在公开详情清晰展示；服务费只标待配置/演示未收取，不默认15%。
- [ ] 发布产生对应商家模拟通知/邮件预览；本票页面三语、窄屏、表单焦点与错误提示可操作。

- [ ] 本票自身检查390px/1440px并抽查320px；切换三语保留输入；有业务事件时核对接收角色、已读记录及模拟邮件；刷新、空/加载/错误/权限不足状态可复现。

## 实施边界与交付证据

仅做M1本地模拟纵向流程，界面、数据状态、持久化、角色反馈和验证一起交付。必要Next.js运行基础随首票建立，不另建只有脚手架但不可演示的票。沿用共用设计系统及已批准规则，不新建真实资金/认证/采集服务。

当前未开工、验收未执行。实施时按项目规则落实工程工作区及开工规格记录；拆票本身不是生产部署批准。完成时记录实际演示步骤、检查结果、已知限制及回退方式。回退本票入口/模拟状态适配应保留其他票功能；共享模拟数据结构变化需支持重置回基准并提前提示，不删除真实资料。
