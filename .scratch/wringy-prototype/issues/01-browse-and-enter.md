# 用户能浏览公开活动并进入模拟工作区

Ticket: M1-01
Milestone: 三端交互原型（M1）
Label: ready-for-agent
Status: ready-for-agent
Assignee: none

**What to build:** 交付可运行的Next.js原型：未登录浏览预置公开活动，选择语言，通过明确标注的Google模拟入口进入本人/商家工作区，并可经演示工具切换运营身份。

**Blocked by:** None（依赖就绪，可认领）

**Spec:** [首阶段原型规格](../../../phase-0/foundation/milestones/prototype-spec-v1.md)

**验收追溯：** P03, P10, P11。这些是原型验收，不代表对应生产业务验收已通过。

## 验收条件

- [ ] 公开目录与详情展示活动费率、门槛、封顶与时间；加入前要求进入模拟身份；没有邮箱或其他登录入口。
- [ ] 使用现有设计系统；三语和手机/电脑基础布局可用，模拟角色不得标为真实权限验证。
- [ ] 三端共用同一模拟记录与固定模拟时钟；本地模拟身份、偏好与预置活动刷新后保留；提供有确认提示的重置演示；只存演示数据。
- [ ] 有空列表、加载与权限不足演示；通知中心有可读的预置模拟通知、已读持久化及模拟邮件预览基础。
- [ ] 界面显示演示数据，不发送Google OAuth、邮件或支付请求；交付可重复启动说明。

- [ ] 本票自身检查390px/1440px并抽查320px；切换三语保留输入；有业务事件时核对接收角色、已读记录及模拟邮件；刷新、空/加载/错误/权限不足状态可复现。

## 实施边界与交付证据

仅做M1本地模拟纵向流程，界面、数据状态、持久化、角色反馈和验证一起交付。必要Next.js运行基础随首票建立，不另建只有脚手架但不可演示的票。沿用共用设计系统及已批准规则，不新建真实资金/认证/采集服务。

当前未开工、验收未执行。实施时按项目规则落实工程工作区及开工规格记录；拆票本身不是生产部署批准。完成时记录实际演示步骤、检查结果、已知限制及回退方式。回退本票入口/模拟状态适配应保留其他票功能；共享模拟数据结构变化需支持重置回基准并提前提示，不删除真实资料。
