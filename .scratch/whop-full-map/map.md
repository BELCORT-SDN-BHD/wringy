# Whop 全业务板块与建设参考地图

Label: wayfinder:map
Status: resolved

## Destination

覆盖 Whop 全部已公开、可发现的业务家族及关键功能，形成分板块研究包、来源覆盖清单和建设依赖参考。逐条区分证实的机制、未实测体验、未公开数据，供之后制定本项目规格；不以研究代替批准。

## Notes

- 2026-09-10 创始人明确扩大为完整分板块拆解；见[创始人输入](../../phase-0/founder-inputs.md)。
- 先前[第一轮地图](../whop-teardown/map.md)仅完成聚焦研究；本次扩展不是已完整覆盖的历史声明。
- research、orchestration、wayfinder；允许交付研究资产。未来产品决策仍由创始人决定。
- 候选 12 板块是研究者为建设参考提出的分类，不是 Whop 内部部门或已批准的代码模块。
- 无 Git 仓库，无客户验证或已批准规格；本轮只做研究与候选拆分，不在缺口上直接编写产品代码。
- 任务图：四份领域研究各自独立；覆盖盘点独立。四份研究→综合板块（需要功能和业务证据）；覆盖盘点→综合板块（需要发现遗漏）；综合板块→语义与链接审核（需要最终边界）。输入冲突先核对原始来源，不无声合并。
- 输出合同：每份领域报告包含角色、收入、功能、流程及异常、归属、依赖、未知与直达来源；覆盖清单保留索引与正文核读的区别；总图必须把 12 板块与共用能力连起来。
- 完成检查：目录所有条目有归类或显式待定；官网边缘产品有去向；各板块有建设边界、依赖及验收候选；无私有数据伪造；无第三方收入误归属；链接与覆盖统计一致。

## Decisions so far

五份研究工单全部关闭。12块、168条功能与边界记录；993索引URL全部归类；独立复核提出的内部遗漏已补齐。

最终入口：[业务地图](../../phase-0/research/whop-full/README.md)；[核验及复核修正](../../phase-0/research/whop-full/verification.md)。研究完成不等于产品规格或架构获批。
